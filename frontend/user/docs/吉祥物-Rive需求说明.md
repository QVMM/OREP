# 竞赛大脑 · 吉祥物 Rive 需求说明

| 项 | 内容 |
|----|------|
| 产品 | 竞赛大脑（OREP 用户端） |
| 用途 | 首页「大脑引擎」主舞台右侧空白槽位的陪伴角色 |
| 交付格式 | **Rive**（`.riv`）+ State Machine 命名表 + 预览链接/录屏 |
| 接入 | Vue 3 Web（`@rive-app/canvas`） |
| 设计对齐 | `frontend/user/DESIGN.md`（暖中性 + 橙 `#e84a1c`） |
| 文档版本 | v1.0 · 2026-07 |

---

## 1. 目标（一句话）

做一只**克制、可读、可状态驱动**的小角色：会 idle、会轻微跟鼠标看、会在「出分 / 有待办 / 待命」等业务态切换表情与动作，**不抢主分数、不卖萌过度、不 AI 鸡汤感**。

---

## 2. 放置与尺寸

| 项 | 规格 |
|----|------|
| 页面 | 用户端首页（`Dashboard`） |
| 位置 | 主区左侧「本场得分 + 读后感」与右侧扫读栏之间的空白（约中上区域） |
| 画板建议 | **220 × 220** 或 **240 × 240**（逻辑像素，2x 导出） |
| 安全边距 | 角色最外轮廓距画板边缘 ≥ 8% |
| 桌面 | 完整跟鼠标（见下） |
| 移动端 | 可不跟手，仅 tap + 业务态（前端可关 look 输入） |

**视觉层级**：分数数字 > 读后感文案 > 吉祥物。角色透明度/动幅都要「陪衬感」。

---

## 3. 角色设定（造型方向）

| 项 | 要求 |
|----|------|
| 名称（暂定） | **小竞**（可改，交付时写死最终名） |
| 物种/形态 | 抽象「小脑袋 / 小助手」即可，**不要**真人、不要复杂 IP 抄袭 |
| 气质 | 冷静教练、轻微俏皮；**禁止**夸张瞪眼、大哭大笑、贴纸感表情包 |
| 主色 | 橙 `#E84A1C`、深橙 `#C43A12` |
| 辅色 | 暖米/白 `#F6F2EC` / `#FFF`；深墨 `#12141A`（线/瞳） |
| 风格 | 简洁矢量、圆角、少杂线；与平台 UI 同一套暖中性 |
| 禁止 | 赛博机甲大面积黑、霓虹、过度 3D 厚涂、版权字体 logo 塞进角色 |

**交付静帧（PNG/SVG 可选）**

1. 正面 idle  
2. 三视图或至少正 + 侧 45°  
3. 表情板：idle / 关注 / 提醒 / 高兴 / 待命  

---

## 4. 动画与交互（必须）

### 4.1 常驻

| 动画 | 说明 |
|------|------|
| `idle` | 呼吸 + 偶尔眨眼；循环；周期 3–5s 自然一点 |
| 幅度 | 位移/缩放总动幅 **&lt; 6%** 画板高度，避免抢眼 |

### 4.2 跟鼠标（桌面）

| 项 | 规格 |
|----|------|
| 方式 | State Machine **Number** 输入（推荐） |
| 输入名 | `lookX`、`lookY`（范围 **-1 ~ 1**，0 为正面） |
| 表现 | **眼睛必须跟**；头可轻转（建议 ≤ 12°）；身体可极轻（可选） |
| 平滑 | 角色内插值或依赖 runtime 平滑；避免抖动 |
| 边界 | 极值时仍保持可爱，不穿模、不翻白眼夸张 |

> 前端会把槽位内/页面相对坐标归一化后写入 `lookX/lookY`。

### 4.3 指针与点击

| 输入 | 类型 | 行为建议 |
|------|------|----------|
| `hover` | Boolean | 轻微前倾/注意；结束回 idle |
| `tap` | Trigger | 短反馈：点头或挥手（≤ 0.8s），然后回当前业务态 |

### 4.4 业务状态（与产品联动）

用 **Number `mood`** 或 **独立 Boolean/Trigger** 均可，**交付时必须附对照表**。推荐：

| mood 值 | 名称 | 触发场景（前端） | 表现建议 |
|--------:|------|------------------|----------|
| 0 | `standby` | 尚未出本场得分 | 放松/轻闭眼，动幅更小 |
| 1 | `online` | 已出分、引擎在线 | 清醒 idle + 可 look |
| 2 | `nudge` | 待办数 &gt; 0 或「待提升」 | 轻敲、看向一侧（暗示「下一刀」） |
| 3 | `celebrate` | 用户点击「打开评分总结」等成功操作 | 短庆祝 1–1.5s，**自动回到** online/nudge |
| 4 | `think` | 加载中（可选） | 短思考，勿死循环抢戏 |
| 5 | `alert` | 错误/失败（可选） | 轻皱眉，禁止惊吓、大红叉 |

**规则**

- `celebrate` / `think` 为**短时态**，结束后回落 `online` 或 `nudge`。  
- 业务态切换时允许 150–300ms 过渡，不要硬切。  
- **不要**自动循环庆祝。

## 5. State Machine 命名约定（给开发）

| 类型 | 命名 | 说明 |
|------|------|------|
| 状态机名 | `BrainMascot` | 唯一主 SM |
| Number | `lookX`, `lookY` | -1 ~ 1 |
| Number | `mood` | 见上表 0–5 |
| Boolean | `hover` | 可选 |
| Trigger | `tap` | 点击 |
| Trigger | `celebrate` | 若不用 mood=3，可用 Trigger |

**Artboard 名**：`BrainMascot`  
**默认皮肤/视图**：单一 Artboard 即可。

## 7. 前端接入约定（供对接）

```text
组件：BrainMascot.vue（由我方实现）
槽位：首页 brain 主区右侧/中缝固定容器 ~220px

每帧或 pointermove：
  lookX, lookY ∈ [-1, 1]

props 示例：
  hasScore: boolean     → mood 0/1
  todoCount: number     → mood 2 when > 0
  busy: boolean         → mood 4
  error: boolean        → mood 5
  onPrimaryClick()      → celebrate 一次
```

移动端：`enableLook=false`，仅 mood + tap。

---

## 8. 验收标准

| # | 标准 |
|---|------|
| 1 | 循环 idle 自然，无闪烁、无破图 |
| 2 | 桌面跟鼠标：眼/头响应清晰，延迟主观可接受 |
| 3 | mood 0–3 切换正确；celebrate 可结束回落 |
| 4 | 与首页并排时不压过「本场得分」主数字 |
| 5 | 色与 `#E84A1C` 体系统一，非另一套插画风 |
| 6 | 文件体积与运行帧率可接受（中端机 60fps 目标） |

---

## 9. 明确不做

- 语音对话、LLM 实时口型  
- 全屏跟随、拖拽扔角色  
- 强引导气泡每分钟弹出  
- 与真实人脸/名人相似  
- 替代右侧扫读信息架构（吉祥物**不承载**密集文案）
