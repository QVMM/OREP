## 一、适用范围

本文档适用于 Phase 1 Round 3（HTML 预览生成阶段）的验收标准。

**适用阶段**：PPT 生成流程的第三轮，基于 Round 2 输出的完整内容生成 HTML 预览文件。

**输入**：Round 2 输出的完整 PPT 内容（content_json）

**输出**：HTML 预览文件

---

## 二、验收条件

### 2.1 渲染要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 页面可正常渲染 | 所有页面可正常打开，无 JS 错误 | 自动化浏览器测试 |
| 主题样式一致 | 主题颜色、字体与配置一致 | 视觉比对 |
| 响应式布局正常 | 不同屏幕尺寸下布局正常 | 多分辨率测试 |

### 2.2 布局要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 页面尺寸 | 1280x720（16:9 比例） | 检查 CSS 尺寸 |
| 元素不溢出 | 无内容溢出容器 | 视觉检查 |
| 对齐一致性 | 元素对齐方式统一 | 间距检测 |

### 2.3 功能要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 翻页功能 | 可正常翻页（点击/键盘） | 功能测试 |
| 图表渲染 | SVG 图表正常显示 | 图表组件验证 |
| 图片加载 | 背景图正常加载 | 网络请求检查 |

### 2.4 内容一致性要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 标题一致性 | HTML 中的标题与 content_json 一致 | 字符串比对 |
| 正文一致性 | HTML 中的正文与 content_json 一致 | 字符串比对 |
| key_points 一致性 | HTML 中的要点与 content_json 一致 | 数组比对 |

## 三、验收检查清单

### 前置条件
- [ ] Round 2 内容生成已完成并通过验收
- [ ] 任务状态为 "processing"
- [ ] content_json 有效

### 渲染验收
- [ ] 页面可正常渲染，无 JS 错误
- [ ] 主题样式一致
- [ ] 响应式布局正常
- [ ] 无控制台 Error 级别日志

### 功能验收
- [ ] 翻页功能正常
- [ ] 图表渲染正常
- [ ] 图片加载正常
- [ ] 无 404 资源请求

### 内容验收
- [ ] 标题与 Round 2 一致
- [ ] 正文与 Round 2 一致
- [ ] key_points 与 Round 2 一致
- [ ] 无乱码字符

### 输出验收
- [ ] HTML 文件生成成功
- [ ] 文件大小合理（< 5MB）
- [ ] 字符编码为 UTF-8

---

## 四、验收流程

1. **输入验证**：检查 Round 2 内容数据完整性
2. **生成执行**：调用 HTML 生成服务
3. **渲染测试**：使用无头浏览器测试渲染
4. **功能测试**：验证交互功能
5. **一致性检查**：比对内容一致性
6. **质量评分**：计算质量得分（满分 100）
7. **结果记录**：记录验收结果到 task_data

**质量得分计算**：
- 渲染要求：30 分
- 布局要求：25 分
- 功能要求：25 分
- 内容一致性：20 分

**通过标准**：质量得分 ≥ 80 分，且无 P0 级问题

## 五、附录

### A. 浏览器兼容性要求

| 浏览器 | 最低版本 | 说明 |
|--------|----------|------|
| Chrome | 90+ | 主要测试浏览器 |
| Firefox | 88+ | 次要测试浏览器 |
| Safari | 14+ | macOS/iOS |
| Edge | 90+ | Chromium 内核 |

### B. 响应式断点

| 设备 | 尺寸 | 说明 |
|------|------|------|
| 桌面 | 1920x1080 | 主要场景 |
| 笔记本 | 1366x768 | 次要场景 |
| 平板 | 768x1024 | 辅助场景 |

### C. 失败处理

| 错误类型 | 处理方式 |
|----------|----------|
| JS 渲染错误 | 标记为失败，检查 JS 错误日志 |
| 资源 404 | 标记为失败，检查资源路径 |
| 布局错乱 | 标记为失败，截图对比 |
| 内容不一致 | 标记为失败，比对差异 |
