## 一、适用范围

本文档适用于 Phase 3（后处理阶段）的验收标准。

**适用阶段**：PPT 生成流程的最后阶段，将批量生成的 HTML 文件转换为最终 PPTX 格式。

**输入**：批量生成的 HTML 文件

**输出**：最终 PPTX 文件

---

## 二、验收条件

### 2.1 成功率要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 导出成功率 | 成功率 ≥ 95% | 统计成功导出数/总任务数 |
| 单页导出时间 | 单页 ≤ 3 秒 | 计时验证 |
| 导出总时间 | 30 页 ≤ 2 分钟 | 总耗时验证 |

### 2.2 格式要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 文件格式 | 标准 PPTX 格式（ISO 29500） | 文件头验证 |
| 幻灯片尺寸 | 1280x720（16:9） | 尺寸检查 |
| 字符编码 | UTF-8 | 编码检查 |
| 文件大小 | 单文件 ≤ 50MB | 文件大小验证 |

### 2.3 兼容性要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| Microsoft PowerPoint 兼容 | 2016+ 版本可打开 | 兼容性测试 |
| WPS 兼容 | WPS Office 可打开 | 兼容性测试 |
| Keynote 兼容 | macOS Keynote 可打开 | 兼容性测试 |
| LibreOffice 兼容 | LibreOffice Impress 可打开 | 兼容性测试 |

### 2.4 内容完整性要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 页面数量一致 | PPTX 中幻灯片数与 HTML 源一致 | 计数比对 |
| 标题完整 | 所有标题正确转换 | 文本比对 |
| 正文完整 | 所有正文内容完整 | 文本比对 |
| key_points 完整 | 所有要点完整 | 文本比对 |
| 图表完整 | SVG 图表正确转换为图片 | 视觉检查 |

### 2.5 样式要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 主题样式保留 | 颜色、字体与 HTML 一致 | 视觉比对 |
| 布局保持 | 布局结构与 HTML 一致 | 布局比对 |
| 图片清晰度 | 导出图片无明显失真 | 质量检查 |

## 四、验收流程

1. **输入验证**：检查 Phase 2 HTML 文件完整性
2. **导出执行**：调用 PPTX 导出服务
3. **成功率统计**：计算导出成功率
4. **格式验证**：验证 PPTX 格式
5. **兼容性测试**：多平台打开测试
6. **内容检查**：比对内容完整性
7. **样式检查**：视觉比对样式
8. **质量评分**：计算质量得分（满分 100）
9. **结果记录**：记录验收结果到 task_data

**质量得分计算**：
- 成功率要求：30 分
- 格式要求：20 分
- 兼容性要求：20 分
- 内容完整性：20 分
- 样式要求：10 分

**通过标准**：质量得分 ≥ 80 分，且无 P0 级问题

## 五、附录

### A. PPTX 文件结构

```
task_123.pptx
├── ppt/
│   ├── slides/
│   │   ├── slide1.xml
│   │   ├── slide2.xml
│   │   └── ...
│   ├── slideMasters/
│   ├── slideLayouts/
│   ├── theme/
│   └── _rels/
├── _rels/
├── docProps/
└── [Content_Types].xml
```

### B. 导出质量标准

| 元素 | 质量标准 |
|------|----------|
| 文字 | 矢量渲染，无毛刺 |
| 图片 | 分辨率 ≥ 72 DPI |
| 颜色 | 与源 HTML 颜色误差 ≤ 5% |
| 布局 | 位置误差 ≤ 2px |

### C. 失败处理

| 错误类型 | 处理方式 |
|----------|----------|
| 导出失败 | 重试机制（最多 3 次） |
| 文件损坏 | 清理后重新导出 |
| 成功率不达标 | 记录失败页面，单页重试 |
| 兼容性问题 | 记录问题，调整导出配置 |
