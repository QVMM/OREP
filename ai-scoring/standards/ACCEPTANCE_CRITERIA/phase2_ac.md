## 一、适用范围

本文档适用于 Phase 2（批量生成阶段）的验收标准。

**适用阶段**：用户确认 Round 3 HTML 预览后，批量生成最终 HTML 文件。

**输入**：确认后的 Round 3 数据

**输出**：批量生成的 HTML 文件

---

## 二、验收条件

### 2.1 成功率要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 批量生成成功率 | 成功率 ≥ 95% | 统计成功数/总任务数 |
| 单页生成时间 | 单页 ≤ 5 秒 | 计时验证 |
| 批量总时间 | 30 页 ≤ 3 分钟 | 总耗时验证 |

### 2.2 文件要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 文件命名规范 | 遵循 `page_{page_index}.html` 格式 | 正则验证 |
| 输出目录结构正确 | 按 `/output/{task_id}/pages/` 目录结构 | 路径检查 |
| HTML 文件有效 | 所有生成的文件为有效 HTML | HTML 解析验证 |
| 文件权限正确 | 文件可读可写（644） | 权限检查 |

### 2.3 内容一致性要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 页面数量一致 | 生成的页面数与预期一致 | 计数比对 |
| 每页内容完整 | 每页 HTML 包含完整内容 | 内容检查 |
| 无内容丢失 | 所有 key_points、body 完整 | 完整性验证 |

### 2.4 资源处理要求

| 验收项 | 条件 | 验证方法 |
|--------|------|----------|
| 资源内联处理 | CSS/JS 已内联或正确引用 | 引用路径检查 |
| 图片路径正确 | 图片引用路径有效 | 路径验证 |
| 字体加载正常 | 字体文件可访问 | 网络请求检查 |

## 三、验收检查清单

### 前置条件
- [ ] Round 3 HTML 预览已确认
- [ ] 任务状态为 "processing"
- [ ] 用户已确认生成批量文件

### 成功率验收
- [ ] 批量生成成功率 ≥ 95%
- [ ] 单页生成时间 ≤ 5 秒
- [ ] 批量总时间 ≤ 3 分钟

### 文件验收
- [ ] 文件命名规范正确
- [ ] 输出目录结构正确
- [ ] HTML 文件有效
- [ ] 文件权限正确

### 内容验收
- [ ] 页面数量与预期一致
- [ ] 每页内容完整
- [ ] 无内容丢失

### 资源验收
- [ ] 资源内联处理正确
- [ ] 图片路径正确
- [ ] 字体加载正常

## 四、验收流程

1. **输入验证**：检查 Round 3 确认数据
2. **批量生成**：调用批量生成服务
3. **成功率统计**：计算生成成功率
4. **文件检查**：验证文件规范和内容
5. **资源检查**：验证资源处理
6. **质量评分**：计算质量得分（满分 100）
7. **结果记录**：记录验收结果到 task_data

**质量得分计算**：
- 成功率要求：40 分
- 文件要求：30 分
- 内容一致性：20 分
- 资源处理：10 分

**通过标准**：质量得分 ≥ 80 分，且无 P0 级问题

## 五、附录

### A. 文件命名规范

| 文件类型 | 命名格式 | 示例 |
|----------|----------|------|
| 单页 HTML | `page_{page_index}.html` | `page_1.html`, `page_2.html` |
| 主文件 | `index.html` | `index.html` |
| 资源目录 | `assets/` | `assets/css/`, `assets/js/` |

### B. 输出目录结构

```
/output/
└── {task_id}/
    ├── pages/
    │   ├── page_1.html
    │   ├── page_2.html
    │   └── ...
    ├── assets/
    │   ├── css/
    │   ├── js/
    │   └── images/
    └── manifest.json
```

### C. manifest.json 结构

```json
{
    "task_id": 123,
    "total_pages": 30,
    "generated_at": "2026-04-15T10:30:00Z",
    "pages": [
        {"page_index": 1, "file": "page_1.html"},
        {"page_index": 2, "file": "page_2.html"}
    ]
}
```

### D. 失败处理

| 错误类型 | 处理方式 |
|----------|----------|
| 生成失败 | 重试机制（最多 3 次） |
| 文件损坏 | 删除后重新生成 |
| 成功率不达标 | 记录失败页面，手动处理 |
| 资源缺失 | 重新处理资源引用 |
