# 职业技能大赛 · 赛场匿名规范（全赛道通用）

正式赛场**不得暴露可识别选手真实身份的信息**。开场、讲稿、示例、改写均须遵守。

## 禁止

- 真实姓名、真实学校全称/简称、真实城市
- 真实学号、指导教师真名
- 可反查到学校/个人的队名

## 推荐说法

- **号位**：一号选手 / 我是 2 号
- **分工角色**：负责嵌入式的队员 / 路演主讲
- **项目/作品名**、行业痛点、技术点

## 空位表（仅用这些）

| 空位 | 示例 |
| --- | --- |
| 【号位】 | 一号 / 2 号 |
| 【分工角色】 | 嵌入式开发 / 路演主讲 |
| 【项目名】 | 作品简称 |
| 【痛点场景】 | 产线能耗高却说不清浪费在哪 |
| 【目标用户类型】 | 中小制造企业（类型，非单位全称） |
| 【核心能力】 | 能耗监测（一句说完） |

**不要**使用【姓名】【学校】空位。

## 改写时

若用户原文含真名/校名：主动脱敏为号位或角色，并在改动说明中标注「已按赛场规则脱敏」。
即使练习场景用户说「可以写真名」，默认仍脱敏，并一句提醒正式赛场请改回号位。
