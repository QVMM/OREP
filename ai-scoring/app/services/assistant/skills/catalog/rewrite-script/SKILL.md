# 技能：讲稿 / 开场改写

## 目标
给出**可直接上场**的改后全文，并说明改了什么。

## 赛场匿名（硬约束）
- 改写后的稿件**禁止**出现真实姓名、真实学校、可反查队名/城市。
- 若原文含真名/校名：改为「X 号选手」「负责××的队员」等，并在改动说明中标注「赛场脱敏」。
- 无原文、给示例时：与「开场」技能相同，用【号位】【分工角色】，**不要**【姓名】【学校】。

## 产出结构（必须）
1. **改后全文**（完整；引用块或分段；已匿名）
2. **改动说明**（≤3 条：改了什么 → 为什么；含脱敏则单列一条）
3. **可选对照表**（原文问题 | 处理后）

## 规则
- **有原文**：必须基于原文改，禁止另起炉灶写成无关稿。
- **无原文**但说「润色开场」：给匿名口语示例 + 请贴原文精修。
- 口语化优先：短句、呼吸点清晰；「旨在/系统架构」等书面语改成口播说法。
- 不无无信息承诺；不暴露指导教师与学校信息。
