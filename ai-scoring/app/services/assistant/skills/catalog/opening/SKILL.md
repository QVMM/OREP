# 技能：路演开场（30 秒）

## 目标
产出可上场的 **约 30 秒（90–130 字）** 开场全文，选手可直接读。

## 赛场匿名（硬约束）
职业技能大赛正式赛场**不得暴露选手真实身份**：
- **禁止**示例或引导：真实姓名、真实学校、真实城市、学号、指导教师真名。
- **必须**用：号位（一号选手/2 号）、分工角色、项目名、行业场景、技术点。
- 空位表**不得**出现【姓名】【学校】；改用【号位】【分工角色】。

## 产出结构（必须按此顺序）
1. **一句话结论**（正式答辩 / 练习；并点明「已按赛场匿名写」）
2. **开场全文**（完整可朗读，用 Markdown 引用块 `>` 包住）
3. **时长与节奏**（约 X 秒；哪里可停顿）
4. **可替换空位**（表格：空位 | 示例填法）
5. **≤3 条使用提示**（列表）

## 推荐示例骨架（无项目信息时也按此匿名结构出）
> 各位评委老师好，我是【号位】选手，本项目中负责【分工角色】。  
> 今天想跟大家聊一个问题——【痛点场景，≤15 字，具体可感知】。  
> 我们做的是【项目名】，简单说，就是帮【目标用户类型】把【核心能力】从「靠经验」变成「靠数据」。  
> 接下来两分钟，演示它怎么落地、效果如何。

## 空位表字段（仅这些）
| 空位 | 填法示例 |
| --- | --- |
| 【号位】 | 一号 / 2 号（赛场编号，勿用真名） |
| 【分工角色】 | 嵌入式开发 / 路演主讲 / 数据分析 |
| 【痛点场景】 | 「产线能耗高却说不清浪费在哪」 |
| 【项目名】 | 作品简称，≤8 字 |
| 【目标用户类型】 | 中小制造企业 / 园区运维（类型，非具体单位全称） |
| 【核心能力】 | 能耗监测 / 排产调度（一句说完） |

## 规则
- 未给项目信息：仍给一版高质量匿名示例；再补问 1～2 个关键信息（项目名、赛道、痛点）。
- 已给项目/赛道：必须用上，禁止空话套模板。
- 禁止拒绝；禁止「请先提供完整材料再写」。
- 语气专业、有气势、不卖萌；口语可用「我们做了个…」但**不要**落成暴露身份的自我介绍。
