# 路演 PPT 资料准备向导开发方案

## 1. 目标

把当前“上传一个 PDF/ZIP 后直接生成”的入口，升级为“资料准备 + 资料补全 + 生成任务”一体化入口。

核心目标：

- 新手没有完整材料时，也能通过结构化填写生成一份可被 PPT Agent 消化的标准资料包。
- 用户有图片、截图、代码、日志、表格、PDF、压缩包时，可以一起提交。
- 生成链路默认按职业院校技能大赛路演准备，不再把模型、模板、页数、语言等高级参数暴露给普通用户。
- Mimo 可以补全文档类和示意类素材，但不能伪造真实截图、合作证明、专利、证书、测试结果和用户反馈。

## 2. 交互设计

采用“分区问卷 + 文件上传 + 补充说明”的方式，不采用纯聊天问答作为主路径。

原因：

- 比赛级 PPT 需要稳定覆盖项目背景、研发历程、实施过程、创新设计、应用价值五大逻辑。
- 纯问答容易遗漏现场实操、团队匿名分工、测试方案、设备清单、备用方案等关键材料。
- 分区问卷能做完整度评分，缺什么就提示什么。
- 自由补充说明保留用户表达复杂约束的能力。

前端默认显示：

- 生成对象：路演 PPT / 论文 PPT。
- 资料模式：已有完整资料、资料不完整、只有项目想法。
- 文件上传：支持 PDF、ZIP、图片、SVG、代码、日志、表格、文档。
- 资料完整度：根据关键字段和上传文件给出 0-10 分提示。
- 分区问卷：项目基础、背景与痛点、系统与技术、现场实操、测试与成果、价值与团队。

前端默认隐藏：

- 生成要求长文本。
- 模型选择。
- 模板选择。
- 页数策略，默认职业赛制 38 页，兼容 35-45 页正式范围。
- 语言。
- 深度研究、视觉审查、图标增强开关。

## 3. 资料补全边界

Mimo 可补全：

- 项目说明书。
- 政策、行业、市场背景的联网研究摘要。
- 技术方案、接口文档、数据库表结构。
- 测试用例、验证方法、现场实操流程。
- 团队匿名分工。
- 设备清单和备用方案。
- APP/后台/设备/SVG 示意图。

Mimo 不可补全为既成事实：

- 真实运行截图。
- 合作证明、证书、专利、软著。
- 用户反馈或调研结论。
- 未提供来源的测试结果。
- 姓名、学校、电话、邮箱等个人信息。

没有真实来源时，只能生成：

- 待采集清单。
- 验证方法。
- 结果记录模板。
- SVG 示意图。
- 可替换的占位材料。

## 4. 后端设计

新增 `ProjectMaterialPreparation` 能力：

- 接收问卷 JSON、补充说明和多个文件。
- 将问卷内容生成标准项目资料包。
- 将上传文件按类型归档：
  - `docs/`：Markdown、文本、文档说明。
  - `data/`：CSV、Excel。
  - `logs/`：运行日志。
  - `code/`：代码、SQL、配置。
  - `images/png/`：图片截图。
  - `images/svg/`：可编辑 SVG。
  - `raw/`：PDF、PPTX 等原始资料。
- 生成 `manifest.json` 标注项目名、资料分类、真实性策略。
- 生成 `README.md` 和核心资料 Markdown。
- 打包为 ZIP，并复用现有 `ProjectZipParser` 转成 `ParsedPaper`。

已落地接口：

- `POST /api/ppt/materials/prepare`

## 5. 前端设计

当前 `PptEditor.vue` 调整为资料准备工作台：

- 路演 PPT 默认选中。
- 单个 PDF/TEX/ZIP 继续走原上传解析链路。
- 多文件、图片、代码、日志、表格或“只有项目想法”走资料包生成链路。
- 填写问卷后自动调用 `/api/ppt/materials/prepare`，拿到 `session_id` 再调用 `/api/ppt/generate`。
- 高级设置折叠隐藏，保留给调试或高级用户。

## 6. 开发步骤

### Phase 1：资料准备 MVP

- 新增资料包准备接口。
- 生成标准 ZIP。
- 前端加入资料模式、文件上传、问卷、完整度评分。
- 默认隐藏高级设置。
- 接入现有生成链路。

### Phase 2：材料质量门禁

- 给问卷生成“缺失材料报告”。
- 区分“可正式参赛”和“仅草稿演示”。
- PDF/PPTX 原始资料加入内容抽取摘要，避免多文件资料包只记录文件名。
- 资料完整度低于门槛时提示用户补充，而不是直接生成低质量 PPT。

### Phase 3：Mimo 补全 Agent

- 将 `mimo_completion_brief.md` 升级为独立补全阶段。
- 联网补政策、行业、市场和就业价值。
- 生成接口、数据库、测试计划、运行记录模板。
- 对每一条补全内容标注：用户提供、联网来源、系统推导、待验证。

### Phase 4：前端体验升级

- 增加“资料清单”页面，用户可看到系统将生成哪些材料。
- 增加“缺失项一键补问”。
- 增加历史任务中的资料包查看。
- 单页再生成时允许选择对应材料重新绑定。

## 7. 验收标准

- 用户只填写项目想法，也能创建合法资料包并进入 roadshow 生成。
- 用户上传多种文件，不再报 `No main .tex file found`。
- 前端默认看不到模型、模板、页数、语言等复杂配置。
- PPT 生成提示词中明确禁止可见页出现个人信息和不当词。
- 系统不会把没有来源的成果写成真实成果。
