# 路演 PPT 可见内容重构开发计划

适用范围：`/ppt-editor` 路演 PPT 分支  
不改范围：论文 PPT 生成链路、非 PPT 功能

## 目标

把职业院校技能大赛路演 PPT 从“Agent 规划稿可视化”改成“参赛作品汇报可视化”。

核心判断标准：

- PPT 可见页只出现评委应该看到的项目事实、结论、图表、证据摘要。
- 评分映射、口令、角色调度、导出门禁、缺资料诊断只进入后台字段、讲稿或系统报告。
- 资料不足时生成预览稿和证据采集口径，不伪造成正式成果。

## 开发步骤

### 1. 内容合同层

新增 `RoadshowContentContract`，集中维护：

- 源资料类型识别：普通项目资料 / Agent 生成母稿。
- 可见文本禁词：评分、采分、口令、操作角色、导出门禁、草稿、模拟数据、占位身份。
- manuscript 单页净化：删除内部字段，只给 SVG Executor 可见正文。
- SVG 可见文字扫描：生成后再次拦截泄漏。

### 2. Roadshow Agent 前半段

改造资料分析、大纲、run-of-show、manuscript 提示词：

- 五大可见结构优先使用：项目背景、研发历程、实施过程、创新设计、应用价值。
- 官方评分只作为后台分析坐标，不写成可见页面标题或正文。
- 现场执行字段必须保留，但明确只能进入内部执行脚本。
- Agent 母稿只抽取事实，不复用其中的字段、门禁、模拟数据和口令。

### 3. SVG Executor 隔离层

在逐页 SVG 生成前：

- 对 roadshow 页调用可见内容净化器。
- 去掉 `judge_focus / command_cue / operator_role / fallback_plan` 等内部字段。
- Runtime reminder 明确禁止渲染评分、口令、门禁、草稿、占位信息。

在 SVG 生成后：

- 静态 Critic 额外扫描 SVG visible text。
- 命中禁词时进入同页修复循环，不重置整套任务进度。

### 4. 正式导出门禁

正式导出前检查：

- 是否还有待补充证据。
- 是否使用了不允许的 PDF 页截图。
- 是否有无来源 KPI。
- SVG 可见文字是否包含后台策划语。

如果不通过：

- 预览仍然保留。
- 任务不再显示“生成失败”。
- 正式 PPTX 下载继续被阻止，并返回具体原因。

### 5. 验证路线

先做低成本验证：

- 单页净化样例。
- SVG 可见文字禁词扫描样例。
- Python 编译检查。
- 用最近的 roadshow 任务重新生成一份小页数样例，看是否还出现“评分要素/口令/操作角色/门禁”等可见文字。

再做完整验证：

- 15 页质量验证。
- 38 页完整职业赛制验证。
- 检查历史记录、预览、正式导出门禁状态是否一致。
