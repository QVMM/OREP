# 工作区左侧导航“纯扣子式”改版设计

## 背景

用户希望把工作区左侧一级导航改成参考图中的“扣子式”侧栏：图标圆润、尺寸统一、视觉上不能太小。当前侧栏宽度为 86px，导航项同时显示图标和文字，选中态使用橙色整项背景与橙色图标底，整体偏密且按钮层级不够清楚。

## 目标

- 让一级导航呈现清晰、轻巧的独立图标按钮。
- 统一七个模块图标的尺寸、描边、圆角感和视觉重量。
- 在不常显文字的情况下，继续保证鼠标和键盘用户能识别每个入口。
- 保持当前路由结构、侧栏宽度和移动端导航行为不变。

## 已确认方向

采用方案 A“纯扣子式”：

- 侧栏保持 86px 宽。
- 每个导航点击区域为 52×52px，圆角 16px。
- 图标统一使用 24×24px SVG 画布，在 52×52px 按钮内显示为 28×28px；未选中时使用 1.9px 圆端线性描边，选中时切换为同语义的实心图标。
- 默认不常显文字标签。
- 当前导航项使用浅灰中性背景和深色实心图标，不使用高饱和整项选中态。
- 品牌橙保留给品牌标识、键盘焦点和必要状态反馈。
- 悬停或键盘聚焦时，在按钮右侧显示黑色名称气泡。
- 气泡使用 14px 文字、36px 最小高度，并通过 8×8px 菱形箭头指向对应按钮。

## 组件与实现边界

### `WorkspaceSidebar.vue`

- 保留现有导航数据、路由跳转和激活态判断。
- 根据同一激活态判断为图标传入 `outline` 或 `filled`，确保路由变化时图标状态同步更新。
- 导航项继续使用语义化链接，并为每个链接提供明确的无障碍名称。
- 将可见文字改为提示气泡内容，不从可访问性树中移除模块名称。
- 增加默认、悬停、聚焦和当前项四种视觉状态。
- 侧栏整体宽度、桌面端显示条件和移动端隐藏逻辑保持不变。

### `WorkspaceModuleIcon.vue`

- 首页、训练营、现场讲解、复盘、协作、AI 应用中心、我的七个图标均保留 `outline` 与 `filled` 两种版本。
- 未选中项使用 `outline`，共享相同的 `viewBox`、1.9px 描边宽度、圆端点和圆连接样式。
- 当前项使用 `filled`，填充色继承按钮的当前文字颜色，并与对应线框图标保持相同语义和视觉重心。
- 未知 `variant` 继续安全回退为 `outline`，未知图标名称继续回退为首页图标。
- 图标含义保持直观，不引入装饰性细节或模块专属尺寸。

### 不在本次范围

- 不修改导航顺序、名称或目标路由。
- 不修改顶部栏、内容区、右侧栏或移动端底部导航。
- 不引入新的图标依赖。
- 不改变品牌 Logo 文件。

## 视觉状态

| 状态 | 按钮背景 | 图标 | 辅助反馈 |
| --- | --- | --- | --- |
| 默认 | 透明 | `oklch(59% 0.008 260)` | 无 |
| 悬停 | `oklch(95.2% 0.004 50)` | `oklch(36% 0.008 260)` | 右侧深色名称气泡 |
| 当前项 | `oklch(92.5% 0.006 50)` | `oklch(25% 0.008 260)` 实心图标 | 始终保持扣子轮廓 |
| 键盘聚焦 | 与当前状态叠加 | 不变 | 2px 品牌橙焦点环和名称气泡 |

状态切换使用 150–200ms 的颜色和阴影过渡，不使用布局动画。尊重 `prefers-reduced-motion`。

## 无障碍与交互

- 每个导航链接保留准确的可访问名称。
- 点击和触控区域为 52×52px，高于 40×40px 最低要求。
- 提示气泡不承载唯一信息，链接本身仍有无障碍名称。
- 键盘 Tab 顺序继续遵循导航 DOM 顺序。
- 焦点样式不能只依赖颜色变化，需要可见的外轮廓。

## 验证标准

1. 七个导航图标视觉尺寸一致，无明显粗细或重心差异。
2. `/training/today` 及现有一级模块路由仍能正确显示当前项。
3. 鼠标悬停每个入口时，显示对应中文名称气泡。
4. 键盘聚焦每个入口时，显示焦点环和名称气泡。
5. 导航链接仍可通过可访问名称查询。
6. 1024px 以上桌面布局不发生横向位移，1023px 以下现有移动端行为不变。
7. 项目构建通过，相关导航自动化测试通过。
8. 桌面端图标计算尺寸为 28×28px，气泡文字为 14px、最小高度为 36px。
9. 气泡左侧箭头可见，颜色与气泡背景一致，且不会遮挡按钮或被侧栏裁剪。
10. 任一路由下仅当前导航项渲染 `is-filled` 图标，其余六项均渲染 `is-outline` 图标；切换路由后两种状态同步切换。
