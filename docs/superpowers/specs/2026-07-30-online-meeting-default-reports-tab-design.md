# 路演训练默认评分报告设计

## 目标

让路演训练页面优先呈现评分报告，同时保留路演记录入口及现有 URL 标签导航能力。

## 交互规则

- 主标签顺序调整为“评分报告、路演记录”。
- 访问 `/online-meeting` 时默认激活评分报告。
- `?tab=reports` 显示评分报告。
- `?tab=meetings` 显示路演记录。
- 缺少 `tab` 或传入无效值时回退评分报告，不主动改写 URL。
- 点击标签继续通过现有 query 参数更新路由，浏览器前进和后退行为保持不变。

## 实现范围

- 调整 `OnlineMeeting.vue` 中两个主标签按钮的模板顺序。
- 将 `activeContentTab` 的默认回退值由 `meetings` 改为 `reports`。
- 更新现有路演训练标签测试，覆盖默认显示、显式 query、无效 query 与移动端无横向溢出。
- 不修改评分报告数据加载、路演记录筛选、视觉样式及其他页面导航。

## 验收标准

- 无 query 进入页面时，“评分报告”位于第一项且处于选中状态。
- 评分报告面板默认可见并正常加载。
- 点击“路演记录”后 URL 为 `?tab=meetings`，对应面板可见。
- 显式 query 和浏览器前进后退切换正确。
- 窄屏页面不产生横向溢出。
