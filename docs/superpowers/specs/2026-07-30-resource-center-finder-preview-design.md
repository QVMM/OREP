# 资源中心 Finder 式浏览与实时预览设计

日期：2026-07-30

## 1. 背景与目标

现有资源中心以分类筛选和文件表格为主，虽然已经具备文件上传、分类、下载和多格式预览能力，但存在以下问题：

1. 页面更像资料台账，文件夹、文件和当前位置之间缺少直观的空间关系。
2. 预览需要显式操作，无法像电脑本地文件管理器一样快速浏览内容。
3. 分类只是筛选条件，缺少文件夹应有的进入、返回、拖拽归类和内容封面反馈。
4. 资源接口当前偏向全局作用域，不符合不同项目团队资料相互隔离的业务预期。
5. 文件按名称下载和预览，遇到同名文件时存在覆盖或取错文件的风险。

本次改造的目标是：

- 将资源中心升级为专业、克制、易用的 Finder 式资料工作台。
- 用品牌化的 Images Badge 文件夹封面呈现文件夹内容。
- 支持桌面端悬停实时预览、触屏端单击预览和沉浸式查看。
- 支持单层文件夹、拖拽归类和“移动到”菜单。
- 将团队资料限定在当前项目团队范围内，同时保留只读公共资源。
- 复用现有多格式预览能力，补齐加载、失败、取消和缓存机制。

## 2. 已确认的产品决策

- 布局方向：Finder 双栏工作区。
- 文件夹层级：仅支持单层文件夹，不支持文件夹嵌套。
- 预览触发：桌面端悬停文件实时更新右侧预览。
- 触屏降级：没有悬停能力时使用单击预览。
- 文件整理：同时支持拖拽进入文件夹和“移动到”菜单。
- 资源作用域：团队资料归属于当前项目团队，各团队相互隔离。
- 公共资料：历史全局资料进入“公共资源”，面向所有团队只读展示。

## 3. 范围

### 3.1 本次包含

- 资源中心根目录、文件夹目录和双栏预览工作区。
- 品牌化 Images Badge 文件夹组件。
- 文件夹创建、重命名、删除空文件夹。
- 文件拖拽归类及“移动到”菜单。
- 文件悬停预览、单击锁定、双击沉浸预览。
- PDF、Word、Excel、PPT、图片、视频、音频和文本类预览。
- 团队作用域、公共资源只读语义和历史数据兼容。
- 按资源 ID 下载、预览和移动的后端接口。
- 响应式布局、键盘操作、减少动态效果和错误恢复。
- 后端、前端组件、契约和端到端测试。

### 3.2 本次不包含

- 不支持多级文件夹或任意深度目录树。
- 不提供跨团队移动、复制或共享团队私有资料。
- 不在线编辑 Word、Excel、PPT 等源文件。
- 不实现多人同时编辑、文件锁或版本冲突合并。
- 不自动把公共资源复制进团队文件夹。
- 不新增桌面客户端或操作系统级文件同步。

## 4. 信息架构

### 4.1 页面头部

页面头部保持平台统一工作区规范，包含：

- 标题“资源中心”和一句简短说明。
- 当前团队上下文，不在页面内重复增加团队选择器。
- “新建文件夹”和“上传文件”两个主要操作。
- 搜索入口和当前目录资料数量。

“上传文件”使用品牌主色实心按钮，“新建文件夹”使用次级按钮。其余筛选和排序操作保持低强调。

### 4.2 根目录

根目录左侧浏览区按以下顺序展示：

1. 文件夹区域。
2. 未归类的团队文件。
3. 公共资源入口。

文件夹采用卡片式 Images Badge：

- 最多叠放三张文件预览封面。
- 悬停时三张封面以小幅旋转和位移展开。
- 文件夹名称、文件数量和最近更新时间位于封面下方。
- 不足三张时使用 PDF、表格、文稿、演示等品牌化格式封面补齐。
- 完全空的文件夹显示简洁空文件夹图形，不伪造内容缩略图。

公共资源使用独立的只读标识，避免用户误以为可以拖入或修改。

### 4.3 文件夹目录

点击文件夹后在原工作区内进入目录，不跳转到独立页面：

- 顶部显示“资源中心 / 文件夹名称”面包屑。
- 提供明确的返回根目录入口。
- 文件列表只显示当前文件夹中的团队资料。
- 当前目录为空时展示可拖入文件的空状态。
- 单层模型下不显示“新建子文件夹”。

### 4.4 双栏工作区

工作区由浏览栏和预览栏组成：

- 左侧浏览栏负责文件夹和文件列表，使用 `minmax(420px, 1fr)` 保证可读性。
- 右侧预览栏使用约 `clamp(360px, 38vw, 560px)` 的宽度。
- 两栏共享一个工作台容器，分隔线可见但不过度强调。
- 页面不使用过窄的固定最大宽度，在常见桌面尺寸上充分利用可用空间。

当视口不足时：

- 中等宽度：预览栏缩为可开合侧边抽屉。
- 手机端：浏览和预览使用两个全屏层级，返回后保持原滚动位置和选中文件。

## 5. 预览交互

### 5.1 桌面端

- 指针在文件行停留约 `150ms` 后，右侧开始加载该文件。
- 快速划过文件时不发起预览请求。
- 指针离开列表后保留最后一次成功预览，不清空面板。
- 单击文件将其设为当前锁定文件，并显示下载、移动、查看详情等操作。
- 双击文件进入沉浸预览。
- 当用户正在操作预览栏时，短暂经过其他文件不替换已经锁定的预览。
- 再次悬停并停留在其他文件上时，恢复实时预览更新。

### 5.2 触屏与键盘

- 触屏设备单击文件加载预览，再次点击或点击“展开”进入全屏。
- 上下方向键移动文件焦点，并同步更新预览。
- `Enter` 锁定当前文件，第二次 `Enter` 打开沉浸预览。
- `Escape` 退出沉浸预览或移动端预览层。
- 文件行、文件夹、菜单和拖拽替代操作均具备清晰焦点样式与可访问名称。

### 5.3 请求控制与缓存

- 使用延迟触发避免悬停抖动。
- 切换文件时取消尚未完成的旧预览请求。
- 缓存最近使用的预览结果；优先使用浏览器内存缓存，不长期保存敏感内容。
- 同一文件在版本未变化时不重复解析。
- 文件更新时间或版本标识变化后缓存自动失效。

### 5.4 格式策略

继续复用现有 `FilePreview.vue` 的格式能力：

- PDF：内嵌分页预览。
- Word：渲染文档内容。
- Excel：展示工作表和单元格内容。
- PPT：展示幻灯片缩略内容。
- 图片：自适应图片预览。
- 视频和音频：原生媒体播放。
- Markdown、文本和 CSV：文本或表格预览。
- 无法解析的旧格式或未知格式：展示元信息、格式说明和下载入口。

## 6. 文件整理交互

### 6.1 拖拽归类

- 文件行可拖拽。
- 拖到文件夹卡片上时，文件夹出现品牌色边框和轻微抬升反馈。
- 公共资源、不可写文件夹和当前所在文件夹不接受放置。
- 放置后前端先更新当前位置，再调用移动接口。
- 接口失败时恢复原位置、原筛选和原预览，并显示明确原因。
- 成功后显示轻量成功提示，同时更新文件夹数量和封面。

### 6.2 “移动到”菜单

键盘用户、触屏用户和不使用拖拽的用户可通过文件操作菜单移动：

- 菜单列出当前团队全部可写文件夹。
- 包含“移出文件夹”，将文件放回根目录未归类区域。
- 当前文件夹置灰且不可选择。
- 公共资源不显示移动操作。

### 6.3 文件夹管理

- 新建文件夹名称必填，团队内不允许同名。
- 支持重命名；重命名不改变内部文件引用。
- 只允许删除空文件夹。
- 非空文件夹删除时提示先移动资料，并提供进入该文件夹的入口。
- 文件夹操作只对当前团队有管理权限的用户开放。

## 7. 数据模型与作用域

### 7.1 资源表

现有 `resource` 表新增或明确以下字段：

- `team_id`：团队资料所属项目团队；公共资源为 `NULL`。
- `category`：保留现有文件夹键，未归类团队资料使用固定根目录键。
- `updated_at`：用于排序、文件夹封面和预览缓存失效。

所有新增团队资源必须写入当前 `team_id`。读取、下载、预览、移动和删除时均由服务端校验团队成员关系和权限，不能只依赖前端传参。

### 7.2 文件夹表

沿用并升级现有 `resource_category` 表：

- 新增 `team_id`。
- 文件夹键在团队内唯一。
- 文件夹名称在团队内做规范化唯一校验。
- `team_id IS NULL` 的系统记录用于公共资源或系统内置分类。
- 不增加 `parent_id`，从数据层限制为单层结构。

### 7.3 历史数据

- 现有 `team_id IS NULL` 的资源按公共资源处理。
- 公共资源继续允许所有已登录用户预览和下载，但禁止移动、重命名和删除。
- 不自动猜测历史资源所属团队，避免错误归属造成资料泄露。
- 若后续需要人工归属，使用管理员迁移工具单独处理，不纳入本次学生端功能。

## 8. 后端接口

### 8.1 列表与文件夹

- `GET /api/resource-center?teamId={id}&folderKey={key}`
  - 返回当前团队可见文件夹、当前目录文件和公共资源摘要。
  - 服务端根据登录用户校验团队访问权。
- `POST /api/resource-center/folders`
  - 创建当前团队的单层文件夹。
- `PATCH /api/resource-center/folders/{folderId}`
  - 重命名文件夹。
- `DELETE /api/resource-center/folders/{folderId}`
  - 仅删除空文件夹。

### 8.2 文件

- `POST /api/resource-center/files`
  - 上传到当前团队根目录或指定文件夹。
- `PATCH /api/resource-center/files/{resourceId}/folder`
  - 移动到目标文件夹或团队根目录。
- `GET /api/resource-center/files/{resourceId}/preview`
  - 按资源 ID 返回预览内容。
- `GET /api/resource-center/files/{resourceId}/download`
  - 按资源 ID 下载原文件。

现有 `/api/ppt-template` 接口暂时保留兼容旧页面，但资源中心的新实现不再以文件名作为资源身份。

### 8.3 移动请求

示例：

```json
{
  "teamId": 3,
  "folderKey": "custom_1785383249000"
}
```

移动到根目录时 `folderKey` 使用固定根目录值或 `null`，由服务端统一规范化。服务端校验：

- 资源存在且属于当前团队。
- 用户属于当前团队并有移动权限。
- 目标文件夹属于同一团队。
- 公共资源不能移动。
- 目标文件夹不是资源当前所在文件夹。

## 9. 前端组件拆分

当前资源中心位于体量较大的 `ScriptList.vue` 中。本次不继续把复杂交互堆入该文件，拆分为独立模块：

- `ResourceCenterWorkspace.vue`
  - 页面数据编排、目录状态、搜索和响应式布局。
- `ResourceFolderBadge.vue`
  - Images Badge 文件夹封面、悬停展开和放置目标状态。
- `ResourceBrowserPane.vue`
  - 文件夹区域、文件列表、面包屑和空状态。
- `ResourceFileRow.vue`
  - 文件元信息、悬停、选中、拖拽和操作菜单。
- `ResourcePreviewPane.vue`
  - 预览加载、错误、工具栏和 `FilePreview.vue` 适配。
- `ResourceMoveMenu.vue`
  - “移动到”菜单及无拖拽替代操作。
- `useResourceCenter.js`
  - 目录数据、请求取消、预览缓存、乐观移动和回滚。

`ScriptList.vue` 仅保留路由入口和必要的上层上下文传递。

## 10. 视觉与动效

### 10.1 视觉规范

- 继续使用平台现有橙红主色、暖白背景、深色正文和中性灰辅助信息。
- 工作台使用清晰边界和克制阴影，不增加大面积渐变背景。
- 选中文件使用低饱和品牌色底和清晰左侧标记。
- 文件格式色只用于小面积图标和封面，不与状态色混用。
- 重要操作明显，排序、筛选和辅助信息保持低视觉权重。

### 10.2 Images Badge 动效

- 静止时三张封面紧凑叠放。
- 悬停时封面分别旋转约 `-6° / 0° / 6°` 并横向展开。
- 总时长约 `180ms`，使用平滑减速曲线。
- 拖拽经过时不继续扇形展开，切换为明确的可放置状态。
- 不使用持续漂浮、闪烁、粒子或大幅弹跳。
- `prefers-reduced-motion: reduce` 下禁用旋转和位移，仅保留颜色变化。

## 11. 状态与错误处理

### 11.1 页面状态

- 首次加载：文件夹和文件列表使用结构稳定的骨架屏。
- 空团队：展示创建文件夹或上传第一份资料的双入口。
- 空文件夹：展示拖拽上传和返回根目录。
- 搜索无结果：保留搜索词并提供清除筛选操作。
- 权限变化：停止后续预览请求，展示无权访问并返回根目录。

### 11.2 预览状态

- 加载中：右栏显示与目标格式相匹配的骨架。
- 成功：替换为完整预览，工具栏保持稳定。
- 解析失败：就地显示失败原因、重新解析和下载原文件。
- 网络失败：允许重试，不清除左侧目录和当前选中项。
- 取消请求：不显示错误提示。
- 不支持格式：展示文件详情卡，不把“不支持”误报为系统故障。

### 11.3 写操作状态

- 新建、重命名、移动和删除期间禁用重复提交。
- 成功使用轻量提示。
- 可恢复失败自动回滚界面。
- 权限、目标不存在等不可恢复错误刷新当前目录，防止继续操作过期状态。

## 12. 安全与性能

- 所有团队资源接口以服务端鉴权结果为准。
- 下载和预览使用资源 ID 定位，并校验规范化后的实际文件路径。
- 不向前端返回服务器绝对文件路径。
- 文件名只用于显示和下载响应头，不再作为存储唯一键。
- 预览请求可取消，减少悬停产生的无效解析。
- 文件夹列表只返回生成封面所需的最多三份摘要，不返回全部预览内容。
- 大文件预览沿用流式或分段策略，不在列表接口中读取文件正文。
- 预览缓存设置数量上限，离开页面后释放对象 URL 和大对象。

## 13. 测试与验收

### 13.1 后端测试

- 团队 A 成员无法读取、预览、下载或移动团队 B 的资源。
- 非团队成员访问团队资源返回权限错误。
- 公共资源可预览和下载，但不能移动、重命名或删除。
- 文件只能移动到同一团队文件夹。
- 删除非空文件夹失败且数据不变。
- 同名文件通过资源 ID 正确预览和下载，不互相覆盖。
- 旧全局资源正确作为公共资源返回。
- 文件夹名称团队内唯一，不同团队允许同名。

### 13.2 前端组件测试

- 文件夹封面正确使用最多三份摘要和格式回退封面。
- 悬停延迟到期后才触发预览，快速划过不请求。
- 新悬停取消旧请求，取消不显示错误。
- 触屏环境使用单击预览。
- 拖拽成功更新目录、数量和封面。
- 拖拽失败恢复原位置和当前预览。
- 公共资源不出现移动操作，也不接受拖放。
- 减少动态效果时不执行扇形展开和位移动画。

### 13.3 端到端验收

1. 切换到团队 A，新建文件夹并上传 Word、Excel、PPT、PDF。
2. 根目录文件夹显示内容封面，悬停展开自然。
3. 进入文件夹，悬停不同格式文件时右侧连续更新预览。
4. 快速划过多行时页面没有请求堆积、闪屏或错误弹窗。
5. 将文件拖到另一文件夹，刷新后归类仍然正确。
6. 使用“移动到”菜单完成相同操作。
7. 双击文件进入沉浸预览，退出后保持目录和滚动位置。
8. 缩小视口后预览转换为抽屉；手机尺寸下单击进入全屏预览。
9. 切换到团队 B 后看不到团队 A 的私有资源。
10. 公共资源在两个团队都可查看，但不能修改。

### 13.4 完成标准

- 资源中心不再依赖固定窄内容宽度，常见桌面尺寸下左右留白均衡。
- 文件夹、目录位置、文件和预览之间的层级一眼可理解。
- 支持团队隔离、公共只读、拖拽移动和菜单移动。
- 现有主要文件类型均能预览或得到明确降级说明。
- 关键后端、前端和端到端测试通过。
- 本地验证后完成线上部署，并在真实线上域名复核团队隔离、上传、移动和预览。
