# 集训任务富文本编辑器增强设计

## 目标

在不改变集训任务现有保存、草稿、发布、附件和学生端读取链路的前提下，增强教师端富文本编辑体验：补齐一级、二级、三级标题与正文层级、预设文字颜色，固定编辑器高度并让工具栏始终可用，同时支持从 Word 粘贴文字和图片。

## 采用方案

采用“固定高度编辑器 + 吸顶工具栏 + 保存时统一上传图片”。粘贴或本地选择的图片先以浏览器临时地址在编辑器中预览，保存任务时复用现有图片上传接口，服务端压缩至 1MB 内并返回正式地址，随后再保存净化后的 HTML。

不采用粘贴即上传，避免未保存任务产生孤立服务器文件；不采用页面级浮动工具栏，避免编辑器与页面滚动相互干扰。

## 教师端编辑器

### 编辑区域

- 整体固定高度约 420px。
- 工具栏固定在编辑器顶部，不随正文滚动离开视野。
- 正文区域独立滚动。
- 字数与格式提示固定在底部。
- 小屏时工具栏可横向滚动，正文区域仍保持可操作高度。

### 格式能力

- 段落类型：一级标题、二级标题、三级标题、正文。
- 行内格式：加粗、链接、预设文字颜色。
- 块级格式：无序列表、有序列表、引用。
- 图片：本地选择与剪贴板粘贴。
- 文字颜色限定为设计系统预设色：正文黑、辅助灰、主题橙、成功绿、提醒黄、错误红，并提供“恢复默认”。

标题层级在任务正文内部使用；页面本身仍只有一个页面级 `h1`，学生端任务内容从内容标题层级正常展示。

## Word 粘贴处理

编辑器拦截粘贴事件并读取 `text/html`、`text/plain` 与剪贴板图片文件：

1. 清理 Word 专有标签、属性、注释和无效样式。
2. 删除仅包含空格、`&nbsp;` 或单个换行的空段落，连续空段落不再进入编辑器。
3. 保留可识别的标题、段落、加粗、列表、引用和链接语义。
4. 对剪贴板 `File` 图片生成临时预览地址并记录为待上传图片。
5. 对 Word HTML 中的 Base64 图片转换为 `File`，生成临时预览地址并记录为待上传图片。
6. 对浏览器无法读取的 `file://`、本地缓存或私有协议图片不直接写入正文，并提示老师重新粘贴图片或使用“插入图片”。
7. 当 Word HTML 与剪贴板文件同时携带同一图片时按顺序去重，避免重复插入。

普通纯文本粘贴维持自然段落，不进行 Word 专用清理。

## 保存与失败处理

- 保存或发布时依次上传所有待上传图片。
- 每张图片上传成功后，将正文中的临时地址替换为服务器地址。
- 任一图片上传失败时中止任务保存，保留当前编辑内容与临时预览，明确提示失败图片，允许老师重试。
- 所有图片上传成功后才清理浏览器临时地址。
- 图片上传继续由服务端统一解码、缩放、压缩和限制到 1MB 内。
- 任务附件上传、排序、删除逻辑保持不变。

## 后端安全规则

- 富文本白名单新增 `h1` 与 `span`。
- `span` 仅允许安全文字颜色，不接受其他内联样式。
- 颜色只保留预设色对应的规范值；其余颜色恢复默认。
- 图片仍只允许平台任务图片目录下的服务器地址。
- 链接仍只允许 HTTP、HTTPS、站内相对路径与页内锚点。

## 学生端展示

- DOMPurify 白名单同步新增 `h1`、`span` 和受控颜色属性。
- 新增一级标题视觉样式，并保持与现有标题、正文、列表、引用间距一致。
- 文字颜色按同一预设色板展示。
- 图片继续自适应内容宽度，移动端不产生横向滚动。
- 学生端只展示已发布训练日的正式服务器图片，不显示 Blob 或 Base64 内容。

## 兼容性

- 已有 `h2`、`h3`、正文、列表、引用、链接和图片内容不需要迁移。
- 原有草稿与发布状态、富文本保存接口、独立附件、权限控制和学生端预览保持不变。
- 旧内容没有颜色标记时使用默认正文色。

## 验证范围

- 教师端构建与后端全量测试。
- 一级至三级标题、正文与六种预设颜色往返保存不丢失。
- 从 Word 粘贴多段文字后无逐行空白段落。
- 从 Word 粘贴图文后图片可立即预览，保存后替换为服务器地址。
- 大于 1MB 的粘贴图片保存后服务器文件不超过 1MB。
- 上传失败时编辑内容不丢失。
- 学生端桌面与窄屏均能正确显示标题、颜色、列表、引用和图片。
- 草稿内容仍不可被学生端访问。
