# 评分报告来源标识去按钮化设计

## 背景

评分报告列表首列当前使用橙色胶囊展示“上传视频”等来源。完整底色、居中文字和大圆角与按钮视觉相近，部分用户会误以为它可以单独点击或用于筛选。

## 方案

采用纯元数据文字：

- 显示为“来源：上传视频”“来源：在线路演”等完整语义；
- 使用平台弱化文字颜色和微型字号；
- 不使用背景、边框、阴影、胶囊圆角或独立悬停反馈；
- 来源文字本身不增加点击、焦点或提示状态；
- 报告行仍是唯一点击目标，“查看报告”继续作为显式操作提示。

## 布局

- 保留来源所在的首列，避免改变标题、分数和操作列的阅读顺序；
- 桌面端首列宽度允许完整显示“来源：”前缀；
- 窄屏继续沿用现有报告行响应式排列，不产生横向滚动；
- 来源文字与报告标题左对齐，不模拟控件的居中形态。

## 可访问性与验收

- 来源仍作为普通文本被辅助技术读取；
- `.source-badge` 的计算样式应无背景图、无可见背景色、无边框、无阴影、无胶囊圆角；
- 来源元素不具备按钮或链接角色；
- 整行点击进入报告的行为保持不变；
- 桌面与 390px 窄屏均无横向溢出。

## 范围

只修改评分报告列表的来源文案与样式及对应回归测试，不调整报告数据、筛选、跳转或其他标签组件。
