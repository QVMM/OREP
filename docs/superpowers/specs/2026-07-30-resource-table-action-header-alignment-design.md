# 资源中心操作列表头对齐设计

## 目标

修正资源中心文件表格中“操作”表头与下方操作按钮视觉轴线不一致的问题。

## 方案

- 保留文件表格现有四列网格与列宽，不改变文件名、大小和更新时间的布局。
- 仅将表头最后一列右对齐。
- 为“操作”文字保留与行内下载按钮一致的右侧安全边距，使文字中心与按钮区域形成稳定的视觉对应。
- `1180px` 以下沿用现有三列响应式网格；最后一列表头仍保持同样的右对齐规则。
- `680px` 以下表头本身隐藏，维持现有移动端行为。

## 验收标准

- 桌面端“操作”表头明显向右移动，与下载按钮区域对齐。
- 文件表格其他三列位置不变。
- 中等宽度下不出现错列或横向溢出。
- 现有资源中心契约测试继续通过，并新增操作列表头右对齐约束。
