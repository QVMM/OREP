# 讲稿怎么对上 PPT 的页

> 日期：2026-08-18  
> 对照稿：用户提供的《慧眼识株》逐字稿（番茄智控）  
> 主规格：`2026-08-18-judge-path-roadshow-design.md`  
> 已有 PPT：`2026-08-18-existing-ppt-full-chain-design.md`  
> 界面：`docs/superpowers/mocks/judge-path-hifi/index.html` 屏「讲稿对页」

上一版默认讲稿步骤上已经写着 `focus = 第 3 页`。真实备赛稿不是这样。真实稿是一份逐字稿：谁说、说什么、括号里写「翻页」、方括号里写动作。不先解决「哪一段对着哪一页」，提纲、改字、换页全是空的。

**不能靠模型去猜这一段是第几页。** 有硬记号就用硬记号。记号不够，摊开对照表让人点。点过一次，绑死在这份讲稿版本 + 这份 PPT 版本上。

---

## 0. 用这份番茄稿说明问题

把原文里的 `（翻页）` 全部标出来，讲稿被切成一段一段。每一段 **正在对着的是翻页之前那一页**（先说完，再翻）。

| 段 | 台上在说什么 | 稿里有没有写看哪一页 | 若只有「下一个翻页对下一页」会怎样 |
|---|---|---|---|
| A | 问好、报名、报作品名，说到「介绍岗位分工」 | 无 | 还在封面 |
| B | 四人报岗位 + 协作机制 | **【动作】PPT 同步展示团队分工表** | 应是分工表。协作是后加的，中间没有翻页 |
| C | 六个部分目录 | 无 | 目录页 |
| D | 「进入第一部分」 | 无 | 过渡，可能仍是目录或章节页 |
| E | 产业、经验、三条政策、菜园、盐碱地、农科院、工程中心 | 无。从「从一颗番茄说起」一直讲到工程中心才翻 | **一段里有 6～8 件能单独成页的事** |
| F | 调研 + 四个痛点（四人轮流，中间不翻页） | **【动作】站到左屏旁依次汇报** | 多半是一页四痛点。若 PPT 做了四页，稿没写翻页 |
| G | 四个技术对四个痛点 | 无 | 方案总览 |
| H | 感知 / 识别 / 回答 / 证明 | 无 | 可能仍是 G，或漏写翻页 |
| I | 识土识图使谱 | 无 | 总思路 |
| J | 解释三识、96%/100ms、技术链、五层架构、时间线 | 无。到「进入核心技能」才翻 | **又是一大段，对着架构/目标/时间线好几页** |
| K | 嵌入式接任务 | 无 | 技能章首页 |
| L | 硬件、联调 | 无 | 传感器页 |
| M | 核心代码、跑程序、拔线、后台验收 | **打开核心代码 / 运行 / 拔线 / 打开后台** | 现场，不是翻页。PPT 可能停在代码页或黑屏 |
| N | 视觉接任务、7:2:1、选型表 | **（PPT展示对比表）** | 对比表是软记号，不是「翻页」 |
| … | 0.23 → 0.96、现场检测【现场结果】 | 有翻页 | 曲线页 / 现场页 |

结论就三条：

1. `（翻页）` 是最硬的记号，但这份稿里 **翻页次数远少于真正该翻的次数**。E、J 两段尤其肥。  
2. 还有别的记号：`【动作】PPT 展示…`、`（PPT展示对比表）`、`【打开后台】`。这些不是翻页，但能对上页。  
3. 现场演示（跑代码、拔线、【现场结果】）**不该对应一页新 PPT**，该停在当前页或空一页给实操。

所以：「第几个翻页 = PPT 第几页」只能当初稿，不能当答案。

## 1. 对上的单位不是「一句」，是「一段正在看的页」

```
讲稿里的一段（两个翻页之间，含说话人）
        ↕ 绑定
PPT 的 0 页、1 页或多页
```

一段可以对：

- 正好 1 页（最常见）  
- 0 页：现场、交接、「请回工位」  
- 多页：一段太肥，稿忘了写翻页，PPT 其实翻了好几张  

绑定记在讲稿版本 + PPT 版本上。任一方 hash 变了，绑定标「过期」，要人看一眼，不自动瞎配。

```json
{
  "spanId": "sp_e",
  "scriptFrom": { "para": 18 },
  "scriptTo": { "para": 31 },
  "speakers": ["项目经理"],
  "cue": { "type": "flip", "raw": "（翻页）" },
  "pages": [7, 8, 9, 10],
  "bind": "user",
  "hold": false
}
```

`bind`：`cue` 稿里写了看哪页 · `seq` 按翻页顺序初配 · `title` 标题对上了 · `user` 人点过 · `none` 对不上。  
只有 `user` 或「cue 且人没反对」才能拿去改 PPT。

## 2. 记号从硬到软，只用到需要问人为止

| 优先级 | 稿里长什么样 | 怎么对页 |
|---|---|---|
| 1 | 人在对照表里拖过、点过 | 以这次为准 |
| 2 | `（翻页）` `请翻到下一页` | 翻完之后的那段，对着「下一张还没被占的页」 |
| 3 | `【动作】PPT 同步展示团队分工表` `（PPT展示对比表）` | 用「分工表 / 对比表」去对页标题和页上的字 |
| 4 | 步骤上已经写着「第 3 页」（旧数据） | 当已有绑定 |
| 5 | 页标题 vs 段里的小标题（四大痛点、五层架构） | 只作建议 |
| 6 | 现场：`【运行】` `【拔掉】` `【现场结果】` `打开后台` | 标「现场，不配新页」 |

模型不准决定绑哪一页。模型最多把 `（PPT展示对比表）` 收成关键词「对比表」，交给第 3 级去对标题。

## 3. 这份番茄稿，系统第一眼必须摊出来的对照表

人话，不要内部编号。初配用「第几个翻页 ≈ 第几页」，肥段和现场单独标黄。

| 讲稿在说 | 初配 | 人要不要动手 |
|---|---|---|
| 问好到报名 | 第 1 页封面 | 一般不用 |
| 四人岗位 + 协作 | 第 2 页分工表（动作里写了） | 协作若另有一页，人把后半段拖过去 |
| 六个部分 | 第 3 页目录 | |
| 进入第一部分 | 第 4 页章节 | 若没有章节页，和上一段并 |
| 产业 → 工程中心（很长） | 先只标「第 5 页起，这一段对着好几页」 | **必须拆。** 建议切在：政策 / 菜园 / 调研前 |
| 四个痛点 | 一页四宫格，或四页但稿没写翻页 | 人看 PPT 有几页痛点，拖一下 |
| 四个技术对四个痛点 | 方案页 | |
| 识土识图使谱 | 总思路 | |
| 目标 96%、五层、时间线 | 又是肥段 | **必须拆** 成目标 / 架构 / 节点 |
| 嵌入式硬件、代码、拔线、后台 | 硬件页；后面是现场 | 代码、拔线、【现场结果】不配新页 |
| 「PPT展示对比表」 | 用「ResNet / YOLO」对标题 | 对不上就问 |

左边是讲稿（智能文档里原样），中间是这段，右边是 PPT 缩略图。拖一段到一页上，就是绑定。

肥段的切法：在讲稿里插入「这里翻页」，不要让系统偷偷改逐字稿正文。插入的是记号，不是改词。

## 4. 和智能文档、结构化讲稿怎么共存

智能文档就是逐字稿。打开这份番茄稿时：

1. 按「角色名：」切开说话人（项目经理、嵌入式工程师…）。对不上的行算旁白/动作。  
2. `（翻页）`、`【动作】`、`【新增】`、`【现场结果】` 收成记号，显示成稿里的小标记，不是普通字。  
3. 两个翻页之间 = 一段。  
4. 同步到 `script.content` 的步骤时：`role` 用说话人，`content` 用这段正文，`focus` 先空着，等对照表填写。  
5. 人在对照表里绑了页，才写 `focus`（例如 `P06`）。没绑之前，小启和改 PPT 都不许当「已经知道是哪一页」。

旧的卡片讲稿如果已经有 `focus`，当第 4 级记号，仍要在对照表里能改。

## 5. 三种情况分别怎么走

**只有讲稿，没有 PPT**  
用记号切段 → 肥段请人加翻页或接受「一页只留一句」→ 按段做页（一页一件事）。E、J 那种肥段，不做一页堆满政策+故事+架构。

**只有 PPT，讲稿是这份逐字稿**  
先读 PPT 每页能改的字（已有 PPT 专文）→ 出对照表，初配用翻页顺序 + 标题 → 黄的人拖 → 再改字/换页。  
翻页 12 次、PPT 28 页是常态，不是错误。多出来的页：装饰、章节、备份，标「讲稿没对着」，人决定拿掉还是留着不讲。

**两边都有，后来改了稿**  
讲稿或 PPT 版本变了，对照表标「有几处可能对不上了」。只重开变了的段，不整表作废。

## 6. 台上怎么联动

路演台：左稿右页。光标在哪一段，右边是绑定的页。  
稿里的翻页记号 = 底条翻到下一页。  
现场段：右边不换页，角上写「这段是现场」。  
没绑定的段：右边空，写「还没对上页，先对一下」。这时不能改 PPT。

---

## 7. 做不到、不许装做得到

- 不能从一大段散文 100% 自动知道对应 7 页里的哪 7 页。  
- 不能把「新增：协作」自动做成新页，除非人加了翻页或拖了绑定。  
- 不能把【现场结果】写成 PPT 上的假数字。  
- 不能因为页数和翻页次数不一致就重排整份 PPT。  

能保证的：

- 所有 `（翻页）` 和 `PPT展示…` 都被收成记号，不丢。  
- 对照表一次看清：哪段对着哪页、哪段太肥、哪段是现场。  
- 人点过的绑定，在两边版本没变时保持。  
- 没绑定的段，系统不改那一页。

## 8. 验收就用这份番茄稿

1. 贴进智能文档，能标出全部 `（翻页）`，四人岗位那段标着「PPT 展示分工表」。  
2. 产业→工程中心、目标→时间线两段标黄，提示太长。  
3. 代码、拔线、【现场结果】标「现场」。  
4. 不点对照表，不能改任何一页 PPT。  
5. 人把「四个痛点」拖到第 9 页，保存后再打开还在第 9 页。  
6. 只改讲稿里一段话，对照表只黄这一段。
