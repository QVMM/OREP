# 学生端静奢动效设计规范

## 目标

为学生端普通工作台页面建立统一、顺滑且克制的动效语言。动效用于解释页面层级和交互反馈，不用于装饰或吸引注意力。

## 覆盖范围

覆盖首页、训练营、复盘、协作、个人中心等由 `WorkspaceShell` 承载的普通业务页面。

以下沉浸式页面不接入统一路由动效，继续使用各自已有交互：

- 在线会议室与现场讲解控制界面
- 正式考试作答页面
- PPT、讲稿等重型编辑器
- 视频播放与全屏预览界面

## 动效架构

### Motion Token

在全局设计 token 中增加统一动效变量：

- 快速反馈：140ms
- 标准反馈：180ms
- 页面切换：220ms
- 标准缓动：`cubic-bezier(0.16, 1, 0.3, 1)`
- 页面进入位移：6px
- 卡片悬停位移：2px
- 按钮按下位移：1px

页面和组件优先引用 token，不新增无语义的孤立时长或缓动曲线。

### 页面切换

在 `WorkspaceShell` 的 `router-view` 外增加统一过渡层：

- 旧页面以较短透明度过渡退出。
- 新页面从下方 6px 淡入。
- 不使用缩放、旋转或横向滑动。
- 页面切换期间保持工作台侧栏、顶部栏和画布稳定。
- `DashboardHome` 的 `keep-alive` 行为保持不变。
- 以路由路径作为过渡 key，查询参数变化不强制重新播放整页动画。

### 交互反馈

按钮：

- 悬停以背景、边框和轻阴影变化为主。
- 按下时下沉 1px。
- 禁用、加载状态不执行位移。

可点击卡片：

- 仅对明确可点击或可导航的卡片生效。
- 悬停抬升 2px，边框轻微偏向品牌橙，阴影略增强。
- 普通信息卡片不添加悬停动效，避免误导用户。

文字链接与行项目：

- 文字颜色平滑变化。
- 已存在箭头时，箭头向右移动 2px。
- 不新增无意义的图标旋转或循环动画。

## 性能与无障碍

- 页面切换只动画 `opacity` 与 `transform`。
- 避免对大面积元素动画 `filter`、`width`、`height` 和阴影模糊半径。
- 支持 `prefers-reduced-motion: reduce`：关闭页面位移、卡片抬升和非必要循环动画。
- 键盘焦点样式保持即时可见，不因动画延迟出现。
- 动效不得阻塞点击、滚动和路由导航。

## 兼容策略

- 复用现有 `--ds-transition` 与组件样式体系。
- 已有合理局部动效保持不变，但统一到新的时长和缓动 token。
- 现有沉浸页面中的状态动画不由本次改造覆盖。
- Element Plus 弹层继续使用组件自身过渡，不叠加整页动画。

## 验收标准

1. 普通工作台页面切换时，侧栏与顶部栏保持稳定，内容区平滑淡入。
2. 连续快速切换导航时不出现白屏、闪烁、双页面重叠或滚动条跳动。
3. 首页缓存与各页面滚动重置逻辑保持正常。
4. 可点击卡片具备轻微抬升反馈，普通展示卡片无误导性反馈。
5. 主次按钮悬停、按下和焦点状态清晰统一。
6. 开启减少动态效果后，页面和交互位移被关闭。
7. 桌面端与移动端均通过生产构建和主要路由实页验证。

## 非目标

- 不重新设计页面布局或视觉层级。
- 不为每个页面增加独立入场编排。
- 不引入动画库。
- 不新增大范围视差、光扫、弹跳或持续漂浮效果。
