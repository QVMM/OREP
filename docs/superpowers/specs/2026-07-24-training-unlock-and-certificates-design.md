# 训练任务开放与教师奖状设计

## 目标

1. 学生任务管理展示当前训练营的全部训练日。
2. 未来训练日默认在北京时间训练日期当天 00:00 开放。
3. 教师可以按训练日提前解锁，也可以恢复为按日期自动开放。
4. 学生不能通过直接访问地址绕过锁定。
5. 教师可以给个人或团队颁发系统生成或自行上传的奖状。
6. 任务管理页面主内容顶部遵循 40px 间距规范。

## 训练日状态

训练日保留现有 `DRAFT/PUBLISHED/CLOSED` 发布状态，并增加可空字段
`early_unlocked_at`。

有效开放条件：

- `DRAFT`：学生只看到训练日占位，状态为“待教师发布”，不可进入。
- `PUBLISHED` 且当前北京时间早于训练日期 00:00，且
  `early_unlocked_at` 为空：状态为“未开放”，不可进入。
- `PUBLISHED` 且已到训练日期 00:00：自动开放。
- `PUBLISHED` 且 `early_unlocked_at` 非空：立即开放。
- `CLOSED`：保留现有完成和查看逻辑。

教师提前解锁按整个训练日生效，当天全部任务一起开放。恢复自动开放时清空
`early_unlocked_at`。

## 后端边界

- 学生训练计划接口返回全部训练日，并为每一天提供：
  `published`、`locked`、`lockReason`、`scheduledUnlockAt`、
  `earlyUnlockedAt` 和 `effectiveUnlockAt`。
- 项目团队看板返回全部训练日摘要。已发布日关联真实任务，未发布日返回只读占位。
- 训练日详情、训练任务详情和任务提交接口统一执行服务端锁定校验。
- 教师端提供提前解锁和恢复自动开放接口，沿用现有教师团队权限校验。
- 所有时间计算固定使用 `Asia/Shanghai`，不依赖服务器默认时区。

## 学生端

- 项目任务队列显示所有训练日。
- 锁定项显示锁图标、训练日和开放时间，不展示可提交操作。
- 点击锁定项不跳转，并明确提示开放时间或“待教师发布”。
- 已开放项继续使用现有任务详情和提交流程。
- 任务管理主容器顶部间距为 40px。
- 独立训练计划页同步使用相同锁定状态，避免两个入口表现不一致。

## 教师端

### 训练日

“计划与日任务”页显示每一天的开放状态：

- 未来且已发布：可“提前解锁”。
- 已提前解锁：可“恢复按日期开放”。
- 未发布：先发布内容，不允许提前解锁。

### 奖状

团队工作台增加“奖状”页签，复用现有
`student_certificate` 和 `student_certificate_recipient`。

颁发支持两种来源：

- `GENERATED`：填写奖状名称、等级、说明、颁发单位和日期，由服务端生成带自动编号的中文 PDF。
- `UPLOADED`：上传 PDF、PNG 或 JPG，保存到统一资源目录。

两种来源均支持选择一个或多个学生，或颁发给整个团队。教师可以查看颁发记录、
预览、下载和撤销。撤销仅将状态改为 `REVOKED`，不删除历史记录和文件。

奖状表增加可空字段：`source_type`、`award_level`、`issuer_name`、
`original_file_name`、`mime_type`。现有记录默认按 `UPLOADED` 兼容。

学生个人中心继续读取 `ACTIVE` 奖状；团队奖状通过团队成员关系展示。

## 文件与安全

- 奖状文件进入现有生产资源根目录下的 `certificates` 子目录。
- 文件名使用随机标识，不使用用户原始文件名作为磁盘路径。
- 上传限制为 PDF、PNG、JPG，并校验扩展名、MIME 类型和大小。
- 下载通过受控接口校验租户、接收人或教师权限，不直接暴露服务器路径。
- PDF 使用项目已有中文字体发现机制，找不到可嵌入字体时返回明确错误，不生成乱码文件。

## 兼容与迁移

- 数据库迁移只新增可空字段，不删除或重命名现有字段。
- 已有训练日没有 `early_unlocked_at` 时自动按训练日期 00:00 计算。
- 已有奖状保持可见；现有 `pdf_url` 继续兼容。
- 不改已有资源文件、任务提交、审核记录和历史奖状记录。

## 验证

- 单元测试覆盖开放时间边界、提前解锁、恢复自动开放和服务端拒绝访问。
- 接口测试覆盖教师权限、奖状两种来源、接收人校验和撤销。
- 前端测试覆盖完整训练日数量、锁定交互、40px 间距和奖状表单。
- 构建用户端、教师端和 Java 后端。
- 部署后验证学生任务页、教师训练日、教师奖状页和学生个人中心。
