# 资源中心文件夹真实夹层开合动效设计

日期：2026-07-30

## 目标

让资源中心的文件夹不再只是静态 SVG 图标。默认状态应表现为文件被收纳在夹层内；悬浮或键盘聚焦时，文件夹前盖轻微向下翻开，文件从夹层内部抽出并扇形展开。

用户已选择视觉方案 A：真实夹层开合。

## 分层结构

文件夹视觉拆为三个独立层级：

1. 后壳：位于最底层，负责表达文件夹主体与标签页，悬浮时保持稳定。
2. 文件层：位于前后壳之间，使用现有真实 PDF、图片、视频缩略图和兜底封面。
3. 前盖：位于最上层，负责遮挡文件底部，形成文件确实插入夹层的空间关系。

前后壳继续复用现有文件夹 SVG 路径和品牌颜色，不引入新的图标依赖。

## 默认收纳态

- 后壳和前盖保持闭合。
- 文件使用 `60 × 42px` 的窥视尺寸。
- 文件底部被前盖遮挡，只露出少量页头。
- 多份文件仅保留轻微的左右错位和角度，避免默认态显得杂乱。
- 空文件夹只展示前后壳，不生成虚假文件封面。

## 悬浮与键盘聚焦态

- 后壳保持稳定，作为视觉锚点。
- 前盖以下边缘为旋转轴，向下移动约 `7px`，并产生约 `-18deg` 的轻度 X 轴翻转。
- 前盖阴影同步下移并变柔，表达前盖与后壳之间产生了开口。
- 文件从 `60 × 42px` 放大到 `112 × 74px`。
- 中间文件上移约 `20px`，两侧文件分别上移并旋转约 `±11deg`，形成扇形预览。
- 动画使用约 `420–480ms` 的收敛型缓动 `cubic-bezier(.22, 1, .36, 1)`。
- 鼠标离开或键盘焦点移走后，前盖与文件按相同路径平滑回到收纳态。

## 颜色与细节

- 团队文件夹继续使用浅橙后壳和品牌橙前盖。
- 调研或自定义文件夹继续使用蓝色体系。
- 公共资源继续使用中性灰色体系。
- 前盖保留现有水平高光线。
- 文件缩略页使用白色边缘和轻阴影，避免与前盖融为一体。

## 可访问性与性能

- `:focus-visible` 与 `:hover` 使用相同的开合状态。
- `prefers-reduced-motion: reduce` 下取消翻盖和文件抽出位移，只保留清晰的静态层级。
- 不新增持续循环动画。
- 真实缩略图继续使用现有懒加载、并发去重和内存缓存。

## 组件改动范围

- `ResourceFolderBadge.vue`
  - 把单一 `resource-folder__shell` 拆为独立的后壳和前盖节点。
  - 调整层级关系和开合动画。
  - 保留拖放、点击、键盘和管理菜单行为。
- `resource-center-finder-contract.test.mjs`
  - 增加前后壳分层与前盖翻转参数的契约检查。

不修改资源数据模型、接口、上传、移动或在线预览逻辑。

## 验收标准

- 默认状态下能够直观看出文件插在文件夹内部。
- 悬浮或键盘聚焦时，前盖本身参与开合，而不是只有文件移动。
- 文件始终位于后壳与前盖之间，不出现穿帮或层级跳变。
- 开合过程连续，无突跳、闪烁或遮挡文件夹名称。
- 空文件夹、单文件、双文件、三文件状态都能正确呈现。
- 低动态模式下不发生明显空间运动。
- 全量前端测试和生产构建通过。
