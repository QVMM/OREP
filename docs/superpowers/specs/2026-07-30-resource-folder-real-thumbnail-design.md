# 资源中心真实缩略图文件夹设计

## 目标

把当前高饱和文件类型卡片改成更接近本地文件系统的真实内容预览。文件夹需要保留明确的前后层级，但不得大面积遮挡缩略图。

## 视觉结构

- 每个有内容的文件夹最多展示三张缩略图。
- 缩略图使用白色页面卡片、浅灰细边框、低强度阴影和小圆角。
- 中间缩略图位于最前，两侧缩略图分别轻微旋转并后退。
- 文件夹位于缩略图前方，宽度小于中间缩略图。
- 默认状态下，文件夹仅遮挡缩略图底部约 18%。
- 悬浮或键盘聚焦时，缩略图整体上移并向两侧展开，遮挡降低到 8%–10%。
- 文件夹悬浮时只下沉约 2px，不放大，不抢夺缩略图焦点。
- 空文件夹只显示文件夹本体，不生成虚假内容。

## 缩略图来源

- PDF：使用现有 `pdfjs-dist` 在浏览器端懒加载第一页并渲染为缩略图。
- 图片：使用文件预览地址直接显示真实图片。
- 视频：在浏览器允许的情况下提取首帧；失败时进入默认封面。
- Word、Excel、PPT、音频和无法解析的文件：使用低饱和默认文件封面，不伪造具体内容。
- 公共资源继续保持只读，缩略图请求沿用现有鉴权 URL。

## 组件边界

- 新增 `ResourceFileThumbnail.vue`，只负责单个文件的缩略图加载、缓存、降级和加载状态。
- `ResourceFolderBadge.vue` 只负责三张缩略图的层叠关系、文件夹前景和交互动效。
- `ResourceCenterWorkspace.vue` 继续提供文件夹的前三份文件，不改变资源中心接口。

## 性能与稳定性

- 仅对进入视口且确实需要显示的缩略图开始加载。
- 同一文件的缩略图按资源 ID 和预览 URL 缓存，组件重新挂载时复用。
- 每个文件夹最多并发加载三份缩略图。
- PDF 使用较低渲染倍率，缩略图尺寸不超过卡片实际显示尺寸的两倍。
- 任一缩略图加载失败只降级当前卡片，不影响文件夹点击、拖拽或其他缩略图。
- 遵守 `prefers-reduced-motion`，减少动效时取消展开位移和旋转过渡。

## 交互状态

- 默认：三张缩略图紧凑叠放，文件夹遮挡底部约 18%。
- 悬浮/聚焦：缩略图展开并上移，遮挡约 8%–10%。
- 拖拽目标：保留现有“移动到这里”提示，提示层位于文件夹前方。
- 加载中：显示低对比度纸张骨架。
- 加载失败：显示带标准文件类型图标的默认封面。

## 验收标准

- 公共资源文件夹能展示前三个 PDF 的真实第一页。
- 缩略图主体在默认和悬浮状态下均可辨认，文件夹不会遮挡主要内容。
- 悬浮展开平滑，不引起卡片高度或网格布局跳动。
- 空文件夹不显示缩略图。
- 文件夹点击、键盘打开、拖拽移动和管理操作保持可用。
- 资源中心契约测试、生产构建和浏览器视觉验收通过。
