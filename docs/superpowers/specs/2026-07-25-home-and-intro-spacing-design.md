# 首页与引导页工作台空间规范

## 目标

- 正式首页四张卡片采用统一的空间密度和内容节奏。
- 引导页交互工作台与正式首页保持一致，并在浏览器缩放、窄桌面和平板宽度下稳定重排。
- 不改变现有产品视觉语言、业务入口或正式首页数据来源。

## 已选方案

采用 B 均衡型：

- 卡片内边距：16px。
- 卡片之间间距：14px。
- 卡片内部主要模块间距：10px。
- 标题区高度、图标尺寸、操作区高度统一。
- 卡片主要操作贴底，内容区自然伸缩。
- 卡片不依赖固定像素行高来制造等高，使用一致的最小高度和内容约束。

## 正式首页

四张卡片统一为 `标题区 + 内容区 + 操作区` 三段结构。

- 标题区：28px 图标盒、10px 图标标题间距、统一最小高度。
- 内容区：使用 10px 垂直节奏，长文本最多两行，避免一张卡片过挤而另一张空旷。
- 操作区：使用 `margin-top: auto` 贴底，顶部留 14px。
- 学习时长图：取消对 170px 固定图高的依赖，使用稳定的最小高度和弹性空间。
- 今日任务：标题、摘要、元信息、提交要求按统一节奏排列；按钮贴底。
- 下场路演：状态面板适度压缩，进度轴与按钮区保持固定节奏。
- AI 评分：分数摘要、五维数据和按钮使用相同的上下间距。

桌面保持两列；窄桌面保持两列但允许卡片自然增高；900px 以下改为单列。

## 引导页交互工作台

- 移除 `78vh + 600px min-height` 的冲突组合。
- 外层使用稳定的宽高比和内容最小高度，不因浏览器缩放裁掉第二行卡片。
- 桌面宽度下完整展示英雄区和四张卡片，不依赖内部滚动才能看到内容。
- 窄桌面下侧栏保持竖向，但卡片可重排并自然增高。
- 平板及移动宽度下侧栏转换为横向导航，四卡片单列。
- 引导页示例数据更新为与正式首页相同的信息丰富度，并删除已经下线的“先看课程”按钮。
- 引导页复用与正式首页一致的 16/10/14 空间规则。

## 验证

- 用户端生产构建成功。
- 正式首页在常见桌面宽度下四卡片密度一致，按钮底线对齐。
- 引导页在 100%、125%、150% 浏览器缩放下不重叠、不裁切主要内容。
- 1440px、1100px、900px、720px 宽度下布局按预期重排。
- 引导页交互导航和卡片点击继续可用。
