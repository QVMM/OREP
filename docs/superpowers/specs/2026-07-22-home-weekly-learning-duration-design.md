# 首页本周学习时长设计

## 背景与目标

首页现有“本周训练趋势”使用训练状态决定柱高。状态是离散类别，柱高却会被用户理解为连续数值，因此图形语义不成立。

本次将该区域改为“本周学习时长”。每根柱子的高度只表示当天真实累计学习秒数，不再表达训练完成、进行中或待开始等状态。

## 数据口径

学习时长沿用个人中心的统一口径，包含以下活动：

- 课程：`course_learning_progress.learned_seconds`
- 考试练习：已提交考试的开始至提交时长
- 路演：参会记录的有效时长
- 协作：`student_learning_session` 中的协作时长

统计使用服务端日期和 Asia/Shanghai 时区，周一为一周起点。负数、空值和没有开始时间的记录不计入。

首页接口增加 `weeklyLearning`：

```json
{
  "weekStart": "2026-07-20",
  "weekEnd": "2026-07-26",
  "serverDate": "2026-07-22",
  "totalSeconds": 8100,
  "activeDays": 3,
  "daily": [
    { "date": "2026-07-20", "durationSeconds": 1800 },
    { "date": "2026-07-21", "durationSeconds": 3600 },
    { "date": "2026-07-22", "durationSeconds": 2700 },
    { "date": "2026-07-23", "durationSeconds": 0 },
    { "date": "2026-07-24", "durationSeconds": 0 },
    { "date": "2026-07-25", "durationSeconds": 0 },
    { "date": "2026-07-26", "durationSeconds": 0 }
  ]
}
```

后端聚合逻辑与个人中心共享，避免两个页面逐渐出现不同口径。首页不额外请求个人中心接口，也不加载奖状、整改等无关数据。

## 界面设计

原“本周训练趋势”卡片原位替换，不新增首页卡片。

- 标题：本周学习时长
- 摘要：本周累计时长、日均时长
- 图表：周一至周日七根柱
- 纵轴：从 0 到当前周的整档上限，至少显示 0、中间值、上限三个刻度
- 柱顶：非零数据展示格式化时长，少于一小时显示分钟，一小时以上显示小时和分钟
- 日期：显示星期与月日，今天增加“今天”文字标识
- 颜色：过去日期使用低饱和中性色，今天使用品牌橙；数值仍以文字呈现，不依赖颜色传达含义

纵轴上限根据本周最大值向上取整到易读档位，例如 30、60、90、120 分钟。所有柱均按同一上限计算高度，柱高与时长保持线性关系。

日均时长使用“本周累计时长 ÷ 本周截至今天已经过的天数”，不把未来日期计入分母，也不只按有记录的活跃日计算。

## 日期与零数据状态

- 过去日期没有记录：显示 `0 分`，保留零高度柱位
- 今天没有记录：显示 `0 分`，今天标识仍然存在
- 未来日期：显示“未到”，不把零时长误解为没有学习
- 全周截至今天均无记录：保留坐标和七日结构，并显示简短说明“完成课程、练习、路演或协作后会自动记录”
- 接口异常：沿用首页整体加载失败与重试逻辑

## 可访问性与响应式

- 图表容器使用 `role="img"`，`aria-label` 按日期朗读每日时长和未来状态
- 柱顶数值、日期和今天标识提供非颜色信息
- 1100px 以下随首页卡片降列；窄屏保持七日横向结构，不隐藏数值含义
- 不引入图表库，使用语义化 DOM 和 CSS，避免增加首页包体与交互成本

## 测试与验收

后端测试：

- 四类活动按日期正确合计
- 周一至周日始终返回七个数据点
- 负数、空值、无效时间不计入
- 服务端日期与周边界正确

前端测试：

- 图表显示七天、纵轴刻度、累计时长和日均时长
- 柱高与分钟数线性对应，最大值不溢出
- 今天、过去零记录、未来日期的文案正确
- 全零数据仍可理解
- 首页重复入口收敛规则继续通过
- 桌面、中屏、窄屏布局通过现有契约测试

## 非目标

- 不展示训练完成状态或完成率
- 不按活动类型堆叠柱状图
- 不提供周切换和历史趋势筛选
- 不修改个人中心的年度学习热力图
