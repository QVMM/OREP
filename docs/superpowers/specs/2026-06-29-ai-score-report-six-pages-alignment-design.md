# AI评分报告六个子页面数据对齐与UI优化设计

## 目标

将五维评分、证据链、表达节奏、现场呈现、改进方案、AI评审团六个页面统一为“证据驱动工作台”风格：数据来自真实报告字段，页面结构规整、小字号、高密度，减少普通卡片堆叠，和总览页的视频过程审计形成同一套产品语言。

## 通用设计

- 页面沿用顶部报告导航，不新增入口。
- 保留 `AiScoreMetricStrip`，但主区域改为高密度工作台：左侧索引或列表，中间主证据/主表，右侧当前上下文或行动建议。
- 所有横向列表和表格必须加 `min-width: 0`、`max-width: 100%` 和必要的内部滚动，避免再次撑破布局。
- 优先展示真实报告数据；缺失时显示“报告未返回”，不能用看似真实的静态示例伪装。
- 数据最多不再硬切 8 条，除非页面明确是摘要；全量数据区用滚动或折叠承载。

## 页面职责

### 五维评分

- 展示五个维度的分值、满分、百分比、差距和整改优先级。
- 当前维度展示评分项明细：得分、扣分原因、建议、关联证据数量、任务入口。
- 维度点击仍写入 `report.selectedDimensionKey`。

### 证据链

- 合并结构化证据锚点、关键帧、ASR转写片段为统一时间线。
- 左侧时间线支持全量滚动；中间展示当前证据帧/文本；右侧展示类型、置信度、关联维度、来源。
- 证据快照和 `EvidenceAnchorList` 保留，但视觉上降级为下方支撑区。

### 表达节奏

- 对齐语速、停顿、口头禅、ASR片段、AI表达教练建议。
- 长停顿列表和问题句要显示时间、上下文、动作建议。
- 训练清单区从“泛建议”改成“本轮数据驱动建议”。

### 现场呈现

- 全量关键帧以小缩略图轨展示，当前帧显示大图和画面说明。
- 音画冲突、屏幕类型、视觉均值、彩排动作集中到同一页。
- 选中帧与全局 `selectedEvidenceFrame` 对齐。

### 改进方案

- 扣分项、优先级、可追回分、团队任务生成形成闭环。
- 工作项列表显示扣分来源、优先级、预计追回、验收标准。
- 保留团队选择和生成团队工作项功能。

### AI评审团

- 去掉与报告整体不一致的暗色视觉。
- 展示官方分、评审团均分、分差、评委数、共识问题、分歧焦点、训练优先级。
- 评委卡片改为浅色矩阵，保留生成/重试功能。

## 验收标准

- `npm run build` 通过。
- 1280px 以上三栏/双栏不互相覆盖，不出现全页横向溢出。
- 六页缺数据时有明确空态，有数据时不显示静态假内容。
- AI评审团风格与其他报告页一致。
- 旧路由和顶部 Tab 不受影响。
