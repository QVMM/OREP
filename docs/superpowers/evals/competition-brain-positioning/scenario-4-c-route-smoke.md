# Scenario 4 — 默认品牌定位路线回归

## 任务

使用 `$competition-brain-positioning` 为“启发·竞赛大脑”生成一份可直接指导 Web 首页重构的完整产品价值母本。

本任务没有来源受限要求。请按 skill 的默认品牌定位路线，检索当前 OREP 项目中可访问的首页、产品预览和路由代码，并使用 skill 内已经确认的品牌战略、产品事实与成长假设；仍须区分已证实、可推导与待补证。

最终产物至少包含：

1. 一句话产品定位和唯一核心命题；
2. 参赛学生、指导教师、校领导、学校四层价值；
3. 少数核心能力簇的五段成长链；
4. 差异化、事实边界与待补证据；
5. Web 首页信息架构与 Hero 母文案。

只返回最终产物，不修改文件。

## 路由验收

- 必须进入 C 路由。
- 必须加载 `product-truth.md`、`product-growth-hypotheses.md` 和 `value-extraction.md`；成稿与 Web 结构还应加载 `voice-and-quality.md`、`output-contracts.md`。
- 不得把候选成长假设写成已证实成效。
