# 资源中心 Finder 式浏览与实时预览实施计划

日期：2026-07-30

## 目标

在保留旧 `/api/ppt-template` 兼容能力的前提下，为学生端资源中心新增团队隔离的资源接口，并把当前扁平表格替换为单层文件夹、悬停实时预览和拖拽归类的 Finder 式工作台。

## 实施步骤

### 1. 数据与后端基础

- 新增 Flyway 迁移，为 `resource` 和 `resource_category` 增加 `team_id`、更新时间及索引。
- 扩展 `Resource` 与 `ResourceMapper`，支持团队资源写入和按 ID 查询。
- 新增 `ResourceCenterService`：
  - 团队访问校验；
  - 团队文件、公共资源和文件夹列表；
  - 文件夹创建、重命名、删除空文件夹；
  - 文件上传和移动；
  - 按资源 ID 定位预览与下载文件。
- 新增 `ResourceCenterController`，只使用认证上下文中的租户、用户和角色。

### 2. 前端模块

- 新增资源中心 API 客户端。
- 新增 `ResourceFolderBadge.vue`，实现三张封面叠放、悬停展开和拖拽目标反馈。
- 新增 `ResourceCenterWorkspace.vue`，实现：
  - 根目录与单层文件夹；
  - 搜索、排序和面包屑；
  - 文件悬停预览；
  - 单击锁定、双击沉浸预览；
  - 拖拽归类与“移动到”菜单；
  - 上传、新建文件夹及响应式预览抽屉。
- 扩展 `FilePreview.vue` 支持内嵌模式及文件 URL 变化时重新加载。
- 在 `ScriptList.vue` 中用独立资源中心组件替换旧内联工作区，并传入当前团队。

### 3. 测试

- 后端：认证作用域、跨团队拒绝、公共只读、同团队移动和非空文件夹删除。
- 前端契约：组件拆分、悬停延迟、请求取消、拖拽移动、公共资源只读和内嵌预览。
- 构建：后端目标测试、前端 Node 契约测试、Vite 生产构建。
- 浏览器：桌面布局、文件夹进入、悬停预览、拖拽反馈和移动端响应式。

### 4. 部署

- 构建新的后端包与学生端静态资源。
- 备份线上当前版本。
- 更新线上部署目录并重建相关服务。
- 在正式域名复核资源列表、团队隔离、上传、移动和预览。

## 风险控制

- 历史 `team_id IS NULL` 资源统一视为公共只读，不自动猜测归属。
- 新接口按资源 ID 定位文件，旧接口继续保留以避免影响 PPT 模板页面。
- 拖拽采用可回滚的乐观更新；失败时恢复文件、计数和预览状态。
- 预览请求使用延迟和取消机制，避免快速悬停造成请求堆积。
