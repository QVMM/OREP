# OREP 用户端与教师端高保真原型设计

日期：2026-07-16

## 1. 目标

以现有 OREP 用户端功能、路由、接口和数据结构为基础，制作一套可独立运行的高保真 HTML 原型。原型优先覆盖学生、队长和教师角色，完整表达从项目准备、学习训练、路演采集、AI 评分、团队整改到再次验证的业务闭环。

本轮管理端不制作页面，只输出角色、权限和数据流逻辑。

## 2. 已确认范围

- 视觉沿用现有橙色首页和用户提供的参考图。
- 顶部快捷栏默认展开、悬浮，不做伸缩动画。
- 全部现有用户端功能必须在原型中有清晰入口或页面映射。
- 教师端使用同一套产品壳层，通过角色、权限和工作重点变化形成教师工作台。
- 页面需要有完整交互和共享状态，关键动作不能只弹出提示。
- 原型使用安全的仓库样本数据，不包含真实凭证、邮箱、会议密码和内部路径。

## 3. 产品组织方式

采用“流程优先统一工作台”。

现有 10 个一级导航入口收敛为 7 个工作领域：

1. 今日工作台
2. 项目准备
3. 学习训练
4. 路演中心
5. 评分复盘
6. 团队执行
7. 成长档案

原有 PPT、讲稿、文件、选题等能力保留为项目准备的二级工作区。现有课程、练习、错题和考试归入学习训练。会议、录制和视频评分归入路演中心。AI 报告、证据、整改、评审团和轮次对比归入评分复盘。

## 4. 角色模型

### 学生

- 查看项目进度与本人下一步。
- 学习、练习、考试。
- 编辑或提交项目材料。
- 参与路演和查看录制。
- 查看评分证据、领取整改项。
- 提交本人负责的任务。

### 队长

队长是项目级关系角色，不是全局账号身份。在学生权限基础上，根据当前项目授权：

- 分配任务。
- 组织材料和版本。
- 绑定路演。
- 跟进项目阶段。
- 查看团队整体准备度。

### 教师

- 创建和管理项目。
- 查看多项目风险与进度。
- 分配任务、调整阶段。
- 审核提交物和材料。
- 发布课程与测评、查看学习进度、人工阅卷。
- 创建排练、指导会议、进行人工评分。
- 复核 AI 证据、确认整改项和再次验证结果。

### 管理角色逻辑

管理端后续围绕租户、组织、账号、角色、资源、首页内容和数据监控展开。本轮仅保留权限矩阵和数据关系，不制作管理界面。

## 6. 页面模板

全平台只使用五种主模板：

1. 总览页：首页、教师工作台、统计趋势。
2. 列表/目录页：课程、考试、会议、文件、录制、报告列表。
3. 工作台页：团队任务、选题、材料、PPT、讲稿。
4. 报告页：结果、证据、整改、评委、对比。
5. 沉浸页：课程播放、专项练习、正式考试、会议室。

## 7. 视觉系统

- 背景：暖米白 `#f6f2ec` / `#faf6f2`。
- 主行动色：竞赛橙 `#e84a1c`，悬停使用 `#c43a12`。
- 主文字：`#12141a`。
- 次文字：`#6b7280`。
- 表面：半透明白、细边线、轻阴影。
- 快捷栏：深黑或炭黑，使用高对比白字和橙色主动作。
- 状态色：绿色表示完成，琥珀表示待处理，红色表示风险，蓝色表示信息。
- 圆角：12 / 16 / 20px。
- 卡片最多一层，不使用多层嵌套卡片墙。
- 交互动效 180ms，浮层 220–300ms，数据绘入 420–700ms。
- 每页最多一个持续环境动效，并支持 `prefers-reduced-motion`。

## 8. 全局壳层

- 桌面端使用约 80px 的一级图标导航栏。
- 复杂模块按需出现约 220px 的上下文二级栏。
- 顶部居中放置默认展开的悬浮快捷栏。
- 顶部右侧提供搜索、消息和账户入口。
- AI 教练为按需打开的上下文侧栏，不永久占用所有页面宽度。
- 1023px 以下进入移动壳层，底部导航保留五项，其他功能进入“全部功能”。

## 9. 悬浮快捷栏

快捷栏固定结构：

- 当前页面/任务上下文。
- 一个主操作。
- 最多两个次操作。
- 一个“更多”入口。

动作由当前路由、角色、项目权限和页面状态决定。沉浸式页面隐藏全局快捷栏，或切换为该任务专用的精简控制条。

## 10. 共享演示数据

主演示项目：

`智农云眼 · 农业病虫害智能预警系统`

核心数据：

- 项目团队 5 人，3 人在线。
- 比赛日期：2026-07-24。
- 最新路演评分：84.2。
- 备赛完成度：74%。
- 评分变化：76.8 → 84.2，第三轮目标 90.2。
- 关键任务：补齐 PPT 终稿、完成错题专项训练、上传逐字稿、参加路演彩排、补充成本收益证据。
- 材料状态：草稿、待审核、已通过、需修改。
- 项目阶段：课程、测评、材料、路演、复盘。

课程、试卷、附件、评分维度、评委画像和任务字段均使用仓库现有安全样本。

## 11. 共享状态与业务流

原型状态保存在浏览器本地，支持重置。

需要贯通的主要旅程：

1. 首页下一步 → 打开任务 → 提交交付物 → 教师审核 → 首页进度更新。
2. 项目准备 → 上传材料/PPT/讲稿 → 进入审核 → 生成或更新团队工作项。
3. 课程学习 → 完成课时 → 进入练习/考试 → 错题复盘。
4. 创建或加入路演 → 会议/录制 → AI 评分 → 打开报告。
5. 评分证据 → 生成整改项 → 同步团队任务 → 完成 → 再次评分 → 对比。
6. 教师风险工作台 → 打开高风险项目 → 审核或分配 → 项目风险状态更新。

## 12. 原型技术结构

原型使用无外部依赖的 HTML、CSS 和 JavaScript：

- 单一入口页面。
- Hash 路由，支持浏览器前进、后退和深链。
- 模块化页面注册表。
- 共享数据与本地状态层。
- 全局事件委托。
- 可访问的弹窗、抽屉、菜单、Toast 和键盘操作。

## 13. 验收标准

- 首页到第一优先任务不超过 1 次点击。
- 评分问题转团队任务不超过 2 次点击。
- 教师首页到待审核事项不超过 1 次点击。
- 每个普通页面只有一个视觉主行动。
- 快捷栏最多一个主操作和两个次操作。
- 六条关键旅程均可走通。
- 所有导航和按钮均有明确结果或下一站。
- 桌面、平板和 390px 移动端无横向溢出。
- 无控制台错误。
- 键盘焦点顺序合理，菜单和浮层支持 Esc。
- 动画支持减少动效模式。
