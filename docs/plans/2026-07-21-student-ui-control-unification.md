# 学生端按钮与输入框逐页统一方案

> 视觉基准：已确认学生首页截图。  
> 原则：先规范、后首页；再从最小页面到复杂工作台逐页迁移。每批完成视觉与交互回归后，才进入下一批。

## 一、统一目标

- 按钮只保留 Default 40px、Compact 34px、Icon 36×36px 三种尺寸。
- Primary 为品牌橙色实底；Secondary 为白底细描边；Ghost/Text 只承担低优先级动作。
- 输入框默认白底、44px、12px 圆角、橙色聚焦环。
- 页面不得自行发明渐变按钮、黑色按钮、蓝灰输入底、不同圆角或不同内部边距。
- PPT 编辑画布允许沉浸式深色，但控件系统必须与学生端一致。

## 三、每页完成条件

1. 默认、hover、active、focus-visible、disabled、loading 六种按钮状态通过。
2. 输入框检查默认、聚焦、错误、禁用、带前后图标五种状态。
3. 1440、1280、1024、390 四个视口无溢出、无按钮换行破坏。
4. 保存同视口修改前后截图，并与首页基准核对。
5. 页面功能、路由、弹窗和真实数据行为保持不变。

## 四、本轮边界

本轮仅完成第 0、1 项：全局规范与学生首页。路演中心和 PPT 页面只登记方案，不修改页面代码。
