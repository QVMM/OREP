# OREP 管理员端学校开通闭环实施计划

日期：2026-07-19  
对应规格：`docs/design/2026-07-19-admin-school-onboarding-hifi-design.md`
状态：已完成并通过自动化与浏览器验证

## 实施原则

- 只改动高保真原型和对应测试，不修改真实业务前后端。
- 管理员端新增独立、带版本的本地演示状态，不把管理员状态塞进教师审核状态。
- 样式和脚本均限定在 `body[data-portal="admin"]` 下，避免影响学生端和教师端。
- 六项一级导航保持不变。
- 先完成状态模型和页面契约，再接入页面交互，最后进行浏览器视觉校验。

## 批次一：管理员演示状态

新增：

- `OREP-高保真原型/admin/js/admin-demo-state.js`
- `OREP-高保真原型/tests/admin-demo-state.test.cjs`

状态包含：

- 学校租户
- 开通任务
- 组织
- 用户
- 角色和数据范围
- 默认业务配置
- 检查结果
- 审计记录

操作包含：

- 创建学校
- 添加组织
- 演示导入用户
- 保存角色和数据范围
- 确认默认配置
- 执行开通检查
- 正式启用
- 重置演示数据

验证：

- 非法状态变化原子失败。
- 有阻塞项时不能启用。
- 启用原因必填。
- 启用后租户、用户和审计保持一致。
- 刷新和跨标签页可以读取同一状态。

## 批次五：学校开通工作台

新增：

- `OREP-高保真原型/admin/tenant-workbench.html`

实现：

## 完成标准

- 八个管理员页面均可通过本地服务访问。
- 主演示闭环可重复完成。
- 所有关键按钮均有真实响应。
- 共享状态跨页面一致并可重置。
- 自动化测试全部通过。
- 三个目标宽度无关键溢出、遮挡或不可达操作。
