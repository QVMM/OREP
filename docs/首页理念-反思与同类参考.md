# 首页为什么「几个都没看上」· 反思与同类参考

## 1. 直接回答你的三个怀疑

| 你的怀疑 | 事实 |
|----------|------|
| 是你设计的效果还是怎么？ | **主要是我按理念骨架自绘的高保真**，不是对照真实产品首页「临摹/翻译」出来的。所以七版共用同一壳（侧栏+暖色+卡片语言），差异主要在信息排布，**看起来像同一产品的七个皮肤**。 |
| 参考产品太少？ | **偏少，且品类偏了。** 上一轮大量引用的是 Linear / Stripe / Notion / 通用 SaaS Dashboard 原则——它们解决的是「工具工作台 / 支付后台 / 文档」，不是「备赛 + 评分闭环」。 |
| 同类型太少？ | **是。** 竞赛大脑更接近：**演练→打分→反馈→再练** 的训练/教练类产品，以及 **面试/语言/体能训练** 的路径型首页；不是 B 端多 KPI 指挥台。 |

结论：不是你选不出来，是**选项集本身同质且错位**。

## 2. 为什么那七版容易「全都没感觉」

1. **壳相同**：侧栏 + 问候 + 白卡 + 同一套组件 → 哲学标签换了，气质没换。  
2. **内容相同**：永远 78 分、同一句读后感 → 故事没拉开。  
3. **理念来自泛 SaaS**：指挥台 / 收件箱 / 能力墙 对「每天登录的备赛教练」天然别扭。  
4. **缺少「真机对照」**：没先给你看 Yoodli / Duolingo / LeetCode / Nike 等首页**在干什么**，直接甩我的演绎，难建立判断锚点。

## 3. 竞赛大脑应对照的「近类」地图（不是远房 SaaS）

### 3.1 同一闭环：练 → 评 → 改 → 再练

| 产品 | 品类 | 首页在干什么（理念） | 对 OREP 的可借 |
|------|------|----------------------|----------------|
| **Yoodli** | AI 演讲/路演教练 | 核心是**开一场练习** + 练完看反馈；VC pitch coach 是「模拟评委气质」 | 首页 = 练场入口 + 最近一次反馈，不是功能墙 |
| **Orai** | 口语教练 | **每日练习场景** + 清晰度等指标；「口袋教练」 | 小步练习、指标服务下一次开口 |
| **PitchBob 等** | 创业 pitch 辅具 | 对话式推进 deck / pitch，少仪表盘 | 过程引导 > 数据墙 |

### 3.2 备考/闯关：有明确「下一题」

| 产品 | 品类 | 首页理念 | 可借 |
|------|------|----------|------|
| **LeetCode / HackerRank** | 面试刷题 | **下一题 / 今日任务 / 进度路径**，不是 KPI 指挥台 | 「下一刀」应像下一题一样显眼 |
| **Pramp / Exponent** | 模拟面试 | **约一场练习**是首页主动词 | 主 CTA = 开一场路演/上传，而非逛模块 |
| **Duolingo** | 语言学习 | 首页就是**一条学习路径**，强制「下一步」 | 备赛路径可视化，砍平权卡片 |
| **Brilliant** | 互动学习 | 打开继续当前课 | 续练感 |

### 3.3 教练 vs 数据：同一运动，两种首页哲学

| 产品 | 理念 | 含义 |
|------|------|------|
| **Nike Training / Run Club** | **教练优先**：今天练什么、体感如何 | 适合「带你打磨」 |
| **Strava** | **轨迹/社群/数据优先** | 适合「记录与比较」 |

竞赛大脑若定位「评分大脑 + 打磨」，应更偏 **Nike 教练**，而不是 **Strava 数据墙** 或 **Stripe 商户后台**。

### 3.4 文档/写作反馈（分数嵌在工作对象上）

| 产品 | 理念 | 可借 |
|------|------|------|
| **Grammarly 类** | 打开文档，分数与建议贴在内容旁 | 总结页已接近；首页应把人**送进最近一场**，而不是另起一座仪表盘 |

### 3.5 国内语境（形态参考，非 UI 抄袭）

- 双创/互联网+ **备赛训练营、路演模拟打磨**：线下流程是「模拟路演 → 评委打分/点评 → 改稿 → 再模拟」。  
- 产品首页应对齐这个**流程记忆**，而不是对齐「企业后台首页」。

## 4. 从近类里抽出的「真共性」（比泛 SaaS 更贴）

| # | 共性 | 反面（我们上次容易踩的） |
|---|------|--------------------------|
| 1 | 首页主动词是 **「练一场 / 继续」** | 主动词散落成 4～6 个入口 |
| 2 | **最近一次结果** 服务下一次练习 | 结果、能力、项目、训练平权展览 |
| 3 | **路径/下一关** 比多 KPI 重要 | 指挥台四格 KPI |
| 4 | 教练产品：**建议 > 仪表** | 先秀引擎能力 |
| 5 | 数据是**旁证**，不是首页主角 | 分数在主卡、条带、侧栏、底卡重复三遍 |
| 6 | 空状态 = **完成第一次闭环** | 空状态堆功能说明 |

## 5. 更贴 OREP 的 3 条「近类哲学」（供下一轮真高保真）

上一轮 7 版作废为「选型主集」；下面 3 条才是近类里站得住的分叉：

### R1 · 路径备赛（Duolingo / 刷题路径）

- **故事**：备赛是一条关卡：交稿 → 出分 → 改一刀 → 再评 → …  
- **首页**：竖向/横向路径，**当前关高亮**，其余灰。  
- **卡片**：关卡节点，不是模块墙。  
- **介绍**：「打开就知道卡在第几关、点哪里过关。」

### R2 · 最近一场工作台（Yoodli / Grammarly）

- **故事**：一切围绕**最近一次路演/评分**。  
- **首页**：大块「本场」+ 反馈摘要 + 再练；历史折叠。  
- **卡片**：**1 场 = 1 主对象**。  
- **介绍**：「打开就是你上一场，改完再练。」

### R3 · 今日训练（Nike 教练）

- **故事**：今天只安排 **1 个训练动作**（可来自评分下一刀）。  
- **首页**：今日任务英雄区；分数小字旁证。  
- **卡片**：几乎一张今日卡。  
- **介绍**：「像私教课表：今天只练这一项。」

（指挥台 / 能力橱窗 / 纯收件箱 可保留为「明确不做什么」的反例，不再进主选型。）
