# Grok.com 设计参照 · 竞赛大脑落地

> 标杆：`https://grok.com/` 浅色模式（2026 实测）  
> 品牌保留：竞赛橙 `#e84a1c` + 现有 Logo（Grok 默认黑钮不照搬）

## 对比度目标（WCAG AA）

| 用途 | 色 | 对白约 | 标准 |
|------|-----|--------|------|
| 主文 | `#0a0a0a` | ~19:1 | AA+ |
| 次文 | `#3f3f46` | ~12:1 | AA+ |
| 说明 | `#71717a` | ~4.7:1 | AA 正文 |
| 次要辅助 | `#8b8b93` | ~3.5:1 | 大字/弱信息 |
| 卡片描边 | `#e4e4e7` | 轻线 | 靠阴影补层级 |
| 主按钮底 + 白字 | `#c43a12` | ~5.3:1 | AA |
| Logo 橙 | `#e84a1c` | — | 装饰 / 大块色 |

## 层级灰阶（轻，不「草稿」）

- 画布 `#f7f7f8` · 侧栏 `#f3f3f4` · 白卡 + 浅线 + 轻阴影  
- 线条不要过深；层级靠底色差与阴影，而不是粗黑框
