# 文件中心页面骨架对齐设计

## 目标

文件中心复用首页与训练营的工作台页面骨架，首屏加载期间不出现白色遮罩闪烁，桌面端顶部和左右边距由 `.workspace-main` 统一提供。

## 已确认方案

- `/project-team/files` 继续使用现有文件中心信息结构和接口。
- 文件中心业务页不再重复设置桌面端页面边距。
- 材料模式强制使用单列根布局，不继承旧准备页在窄桌面端预留的 76px 导航栏位。
- 移除作用于整个业务页的 Element Plus `v-loading` 白色遮罩。
- 加载时保留文件中心头部和列表容器，在列表区域显示轻量骨架行。
- 移动端仍使用平台统一的 `18px 16px 96px` 页面边距。

## 验收标准

1. 从任务管理进入文件中心时不出现白色整页闪烁。
2. 1269px 和 1288px 宽度下，文件中心标题与训练营标题使用相同的页面起始位置。
3. 文件中心根布局不再产生隐藏的 76px 空白列。
4. 加载结束后原有文件数量、筛选项和文件操作保持不变。
5. 构建通过，浏览器中接口成功时显示原有资料，失败时仍显示已有错误提示。
