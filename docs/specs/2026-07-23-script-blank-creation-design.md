# 空白讲稿创建设计

## 目标

讲稿制作支持两种创建方式：

- 空白创建：不依赖赛制模板，由用户自行搭建章节、角色和讲解步骤。
- 模板创建：保留现有模板内容、角色和章节结构。

## 空白讲稿最小结构

空白创建后直接进入讲稿编辑器，并持久化以下最小数据：

- 标题：`未命名讲稿`
- 一个章节：`新章节`
- 章节时长：5 分钟
- 步骤：空数组
- 一个角色：`主讲人`
- 来源：`manual`

最小章节保证编辑器打开后立即存在可操作区域；不预置讲解步骤、赛制结构或示例内容。

## 交互

“新建讲稿”弹窗分为“从零开始”和“使用模板”两个区域。空白讲稿入口固定在顶部，模板列表位于其下方。

创建请求提交期间禁用空白入口并显示创建状态，避免重复生成。创建成功后关闭弹窗并进入新讲稿；失败时保留弹窗并显示错误提示。

## 验证

1. 空白入口可创建讲稿并进入详情页。
2. 编辑器正确显示一个空章节、一个主讲人和零个步骤。
3. 用户可继续添加章节、角色和步骤，自动保存链路保持可用。
4. 原有模板创建功能不受影响。
