# 创建团队表单输入框遮盖修复

## 问题

教师端创建团队第一步使用双列表单。原生输入框设置了 `width: 100%`，但未使用 `border-box`，因此左右内边距和边框会叠加到网格轨道宽度之外，侵入相邻列并遮盖“项目名称”输入框。

## 目标

- 团队名称和项目名称输入框保持清晰的 16px 列间距。
- 文本域、原生输入框、赛道选择器和日期选择器均不超出各自网格轨道。
- 保持桌面端双列、760px 以下单列的现有布局。
- 不改变字段顺序、尺寸风格、校验和业务逻辑。

## 方案

在 `TeamCreateView.vue` 的局部样式中：

1. 将双列轨道从 `1fr 1fr` 改为 `minmax(0, 1fr) minmax(0, 1fr)`，允许轨道在内容较宽时正确收缩。
2. 为 `.wizard-field` 增加 `min-width: 0`，避免网格子项的默认最小内容宽度撑开列。
3. 为原生输入框、选择器、文本域和成员搜索框增加 `box-sizing: border-box`，确保 `width: 100%` 包含边框与内边距。
4. 保留当前移动端断点及单列规则。

## 验证

- 增加样式契约测试，覆盖 `minmax(0, 1fr)`、`min-width: 0` 和 `box-sizing: border-box`。
- 运行教师端全部测试。
- 运行教师端生产构建。
- 在 `/teacher/team/create` 的当前桌面尺寸下检查两个首行输入框无重叠，并检查赛道、日期与简介控件边界。
- 缩小页面宽度，确认 760px 以下正常切换为单列。
