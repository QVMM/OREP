# 讲稿编辑器整体重构说明

## 目标

将讲稿编辑器从“卡片式后台表单”重构为适合路演团队持续写作的工作台。正文是主任务，章节、角色、时长、提示和转场作为上下文辅助；视觉与首页、训练营统一。

## 已确认方向

- 使用暖白画布、白色内容面、细边框、克制阴影和品牌橙主操作。
- 左侧保留可快速跳转的章节大纲，但压缩统计信息并将角色管理移入抽屉。
- 主区采用连续写作流：角色、时长和焦点是步骤头部元数据，讲解正文获得最大面积。
- 演示提示与转场话术进入可展开的辅助信息区，降低常态视觉噪声。
- 空白章节提供明确的首步引导，不再保留大面积无意义空白。
- 自动保存、模板保存、PDF 导出以及现有数据结构保持不变。

## 信息架构

1. 顶部工具栏：返回、讲稿标题、自动保存状态、存为模板、导出 PDF。
2. 左侧章节大纲：总时长、章节/步骤数量、章节列表、添加章节、团队角色入口。
3. 主编辑区：章节标题与时长、紧凑摘要、连续步骤编辑、添加步骤。
4. 团队角色抽屉：查看、删除和新增角色。

## 视觉规范

- 仅使用现有 `--ds-*` 设计 Token。
- 页面标题 24px/700，章节标题 24px/700，正文 15px/1.7。
- 4px 基础间距阶梯，主要卡片圆角 16px，输入框圆角 12px。
- 品牌橙只用于选中状态和主要行动；保存成功使用绿色语义色。
- 辅助文字不低于 12px，输入标签保持可读对比度。

## 响应式与无障碍

- 1100px 以下缩窄章节栏；900px 以下改为纵向布局。
- 720px 以下工具栏换行，步骤元数据单列。
- 保存状态使用 `aria-live`，图标按钮提供可读标签，章节项保留键盘激活。
- 动效遵循 `prefers-reduced-motion`。

## 验收

- 空白讲稿、包含步骤的讲稿、角色抽屉、添加章节/步骤、自动保存和导出入口均可用。
- 构建通过，无 Vue 模板或样式错误。
- 在浏览器中验证桌面和窄屏布局，重点检查正文可读宽度、滚动和焦点状态。
