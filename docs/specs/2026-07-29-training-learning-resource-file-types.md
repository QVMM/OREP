# 集训营学习资料文件类型扩展设计

## 背景

教师在“集训营 → 计划与日任务 → 今日学习”上传学习内容时，教师端文件选择器和后端上传服务目前只接受：

- 视频：MP4、WebM、MOV；
- 文档：PDF、PPT/PPTX、DOC/DOCX。

因此 Excel 等常用教学资料即使可以从操作系统文件选择器中找到，也会被前端过滤或被服务端以“不支持该文件类型”拒绝。教师端空状态文案也只展示视频、PDF、PPT 和 Word，无法准确表达平台能力。

学生端现有文件预览组件已经具备 XLSX、图片、音频、Markdown 和文本等多种格式的基础预览能力，但学习资料上传白名单尚未与这些能力对齐。

## 目标

- 为“今日学习”统一扩展常用教学资料的上传白名单。
- 保证教师端选择器、界面文案、后端扩展名判断、文件内容校验和 MIME 类型完全一致。
- 能在线预览的格式继续使用预览组件；不能可靠预览的格式提供明确的下载入口。
- 保持现有学习资源数据结构，不因文件格式扩展引入数据库迁移。
- 为非法扩展名、伪造文件内容和超出大小限制提供明确错误信息。

## 非目标

- 不允许任意文件上传，不采用“只拦截少数危险扩展名”的黑名单策略。
- 不支持可执行文件、脚本文件、SVG、安装包、磁盘镜像或宏文件。
- 不新增分片上传、断点续传或文件在线编辑能力。
- 不改变 AI 评分视频单独约定的 5GB 上传限制。
- 不改变本功能现有学习视频 500MB、其他学习资料 50MB 的大小限制。

## 正式支持清单

| 分类 | 扩展名 | 后端资源类型 | 最大大小 | 学生端行为 |
| --- | --- | --- | --- | --- |
| 视频 | MP4、WebM、MOV | `VIDEO` | 500MB | 在线播放并记录视频学习进度 |
| 音频 | MP3、WAV、M4A | `DOCUMENT` | 50MB | 在线播放，按普通资料标记已学 |
| PDF | PDF | `DOCUMENT` | 50MB | 在线预览 |
| Word | DOC、DOCX | `DOCUMENT` | 50MB | DOCX 优先在线预览；DOC 失败时下载 |
| 演示文稿 | PPT、PPTX | `DOCUMENT` | 50MB | PPTX 优先在线预览；PPT 失败时下载 |
| 表格 | XLS、XLSX、CSV | `DOCUMENT` | 50MB | XLSX 优先在线预览；XLS 失败时下载；CSV 文本预览 |
| 文本 | TXT、MD | `DOCUMENT` | 50MB | TXT 文本预览；Markdown 安全渲染 |
| 图片 | JPG、JPEG、PNG、GIF、WebP | `DOCUMENT` | 50MB | 在线预览 |
| 压缩包 | ZIP、RAR、7Z | `DOCUMENT` | 50MB | 不在线解压，直接下载查看 |

新增格式继续归入 `DOCUMENT`。前端对用户统一称为“资料”，具体格式由文件扩展名和 MIME 类型决定；数据库中的 `resource_type` 仍保持 `VIDEO`、`DOCUMENT`、`LINK` 三类。

## 方案选择

### 方案一：只扩展教师端文件选择器

改动最小，但会产生“本地可以选择、服务器仍然拒绝”的假支持，不能满足线上一致性要求。

### 方案二：前后端统一分类白名单并校验文件内容

教师端、后端和学生端围绕同一份正式清单实现。后端仍是最终可信边界，并校验扩展名、文件头和大小。该方案安全性、兼容性和维护成本较均衡，作为本次实施方案。

### 方案三：允许任意文件，仅拦截危险格式

扩展性最高，但更容易上传可执行内容、浏览器可解析的主动内容或无法识别的文件，不适合线上教学平台。

## 教师端交互

### 上传入口

- 按钮文案由“上传视频或课件”改为“上传视频或资料”。
- 文件选择器的 `accept` 必须覆盖正式支持清单中的全部扩展名及主要 MIME 类型。
- 保留多文件选择和现有上传进度、成功、部分成功、失败反馈。

### 能力说明

空状态使用简洁文案：

> 支持视频、Office、PDF、表格、图片、音频、文本和压缩包，或添加外部课程链接。

在上传按钮附近增加可查看的格式说明，列出完整扩展名和大小限制，避免把全部格式长期堆叠在主界面。

### 错误提示

- 不支持的扩展名：提示“暂不支持该文件类型”，并附支持格式摘要。
- 文件内容与扩展名不一致：提示“文件内容与扩展名不匹配，请检查后重新上传”。
- 文件过大：视频提示最大 500MB，其他资料提示最大 50MB。
- 批量上传时延续现有部分成功机制，每个失败项保留文件名和具体原因。

## 后端校验

### 扩展名分类

后端维护按用途分组的不可变扩展名集合：

- `VIDEO_EXTENSIONS`
- `AUDIO_EXTENSIONS`
- `OFFICE_EXTENSIONS`
- `TEXT_EXTENSIONS`
- `IMAGE_EXTENSIONS`
- `ARCHIVE_EXTENSIONS`

除 `VIDEO_EXTENSIONS` 外，其余格式均写入 `DOCUMENT` 资源类型。服务端错误提示由统一支持清单生成，避免手写文案与实际集合漂移。

### 文件内容校验

后端不能只信任浏览器提交的文件名和 `Content-Type`：

- PDF 校验 `%PDF`；
- DOC、PPT、XLS 校验 OLE Compound File 文件头；
- DOCX、PPTX、XLSX、ZIP 先校验 ZIP 文件头；其中 OOXML 文件还要以只读、有限额方式检查容器目录，分别确认存在 `word/`、`ppt/`、`xl/` 和 `[Content_Types].xml`；
- MP4、MOV、M4A 校验 ISO Base Media `ftyp`；
- WebM 校验 EBML 文件头；
- MP3 校验 ID3 或 MPEG 音频帧同步头；
- WAV 校验 `RIFF` 和 `WAVE`；
- JPG/JPEG、PNG、GIF、WebP 分别校验对应图片文件头；
- RAR、7Z 校验对应归档文件头；
- TXT、CSV、MD 没有稳定的魔数，读取有限大小的文件头，拒绝包含 NUL 字节或明显二进制内容的文件，同时兼容 UTF-8 BOM 和常见中文文本编码。

OOXML 与 ZIP 都以 ZIP 为容器。校验时不把条目解压到磁盘，也不读取完整条目内容；只遍历有限数量、有限总名称长度的目录项来识别 OOXML 类型，超过安全阈值直接拒绝。这样既能区分普通 ZIP 与 DOCX、PPTX、XLSX，也避免为格式识别引入压缩包炸弹风险。

### MIME 类型

存储的 MIME 类型由服务端根据已经验证的扩展名生成，不直接采用客户端传入值，防止上传内容被浏览器当作 HTML 或脚本执行。未知或需要下载的格式使用安全的 `application/octet-stream` 或对应标准 MIME。

### 存储与访问

- 沿用服务器生成的 UUID 存储名，用户文件名只作为展示信息保存。
- 保留路径归一化和上传根目录边界检查。
- 预览端点只服务已经通过租户、用户和角色权限校验的资源。
- ZIP、RAR、7Z 使用附件下载响应，不在浏览器中以内联内容打开。

## 学生端预览与下载

- XLSX、DOCX、PPTX、PDF、图片、音频、TXT、CSV、Markdown 使用现有预览组件或其轻量扩展。
- DOC、PPT、XLS 等旧版二进制 Office 格式若预览组件无法解析，显示“该格式暂不支持在线预览，请下载后查看”，并提供下载按钮。
- ZIP、RAR、7Z 不进入预览加载流程，操作按钮直接显示“下载资料”。
- 教师端资源列表同样根据格式显示“预览”或“下载”，避免让用户点击必然失败的预览。
- 学习完成逻辑保持不变：视频根据播放进度记录；其他资料由学生查看或下载后手动标记已学。

## 数据流

1. 教师选择正式支持清单中的一个或多个文件。
2. 教师端先根据扩展名做即时筛选，并进入现有上传进度流程。
3. 后端按扩展名确定视频或普通资料分类及大小限制。
4. 后端验证文件头，再使用服务端 MIME 映射保存文件和资源记录。
5. 成功资源立即进入教师端列表；失败资源显示文件名和原因。
6. 学生打开已发布训练日后，根据文件格式进入播放、预览或下载流程。

## 兼容性

- 现有视频、PDF、Word、PPT 上传行为保持不变。
- 已存量资源不需要迁移。
- `resource_type` 枚举不变，现有统计中的“视频 / 资料 / 链接”数量不受影响。
- 文件预览失败不会影响下载和手动标记学习完成。
- 教师端与学生端不依赖客户端提交的 MIME 才能识别格式。

## 测试

### 后端

- 每一种正式支持扩展名都能被正确分类并返回正确 MIME。
- 有效文件头通过；伪造扩展名或错误文件头被拒绝。
- 普通 ZIP 改名为 DOCX、PPTX 或 XLSX 时被拒绝，三种 OOXML 格式互相改名时也被拒绝。
- TXT、CSV、MD 的正常文本通过，包含 NUL 字节的明显二进制内容被拒绝。
- 视频超过 500MB、其他资料超过 50MB 时返回对应错误。
- 不支持的扩展名返回统一、准确的格式说明。
- 新增格式写入 `DOCUMENT`，视频仍写入 `VIDEO`。

### 教师端

- 文件选择器 `accept` 覆盖正式支持清单。
- 按钮和空状态使用“资料”而不是仅“课件”。
- 批量选择新增格式时继续展示上传进度与汇总结果。
- 后端拒绝文件时显示文件名和明确原因。
- 压缩包等不可预览格式显示下载操作。

### 学生端

- XLSX、图片、音频、TXT、CSV、Markdown 能进入对应预览。
- DOC、PPT、XLS 预览失败时能下载。
- ZIP、RAR、7Z 直接下载，不触发在线预览。
- 新增资料仍可正常标记已学。

### 回归验证

- 运行后端学习资料服务相关测试。
- 运行教师端和学生端专项测试。
- 运行教师端、学生端生产构建。
- 在本地页面分别验证 XLSX 在线预览、图片预览、音频播放、CSV 文本预览、ZIP 下载和伪造文件拒绝。

## 验收标准

- 教师可以从“今日学习”上传正式支持清单中的全部格式。
- 前端允许选择的文件不会仅因前后端格式白名单不一致被后端拒绝。
- 后端不会仅凭扩展名或客户端 MIME 接受伪造内容。
- 学生对支持预览的格式能直接查看，对不支持预览的格式能明确下载。
- UI 中的支持格式、大小限制和后端实际行为一致。
- 原有上传进度、部分成功、学习进度和外部链接能力不受影响。
