## 第 2 页｜问题

**任务**：只建立「为什么要变」，不讲产品功能。

**标题**：材料改了，不等于学生会了。

**支撑**：有底气上场的，不是更漂亮的文件，而是知道问题在哪、为什么改、敢把下一版带回现场验证。

| 常见做法 | 实际缺什么 |
|----------|------------|
| 堆材料、改 PPT | 判断写进可检查成果，并在项目里持续备齐 |
| 盲目加练、打卡 | 对准当前短板的练 |
| 上场一次就散 | 可回看的演 + 能对位的评价 |
| 一个总分 /「还不够」 | 能落地的改：谁改、改什么、怎么再验 |

**页末钩子**：所以需要同一项目上的节奏——先备齐 → 再练准 → 再上场 → 再评价 → 再改进。下一页只讲这五个字。

## 第 3 页｜方法（全册唯一总地图）

**任务**：讲透备-练-演-评-改。后面页禁止再定义这五个字。

**标题**：备 · 练 · 演 · 评 · 改

**一句**：同一参赛项目为底座；五步按序发生；改完可再备/再练/再演。

| 字 | 含义 | 产品承接（点到为止） |
|----|------|----------------------|
| 备 | 该交的、该讲的备齐 | 工作台、待办、协作、日报、讲稿材料 |
| 练 | 对准短板练 | 训练日、今日学习、提交批改 |
| 演 | 真实上场，留样本 | 在线路演、录制回放、上传视频 |
| 评 | 反馈有结构、有依据 | 多维 AI 报告、整改线索 |
| 改 | 教师判断后改，再验证 | 审核发布任务 → 学生跟进 |

**收口句**：项目是底座；备练演评改是节奏；证据是依据；教师是裁决；下一轮是检验。

**边界半句（仅此半句）**：金奖是方向不是承诺；平台组织路径，能力形成仍看行动与证据。

## 第 4 页｜产品

**任务**：只回答「五个字各落到哪些可演示能力」。不再解释字义。

### 备
- 项目团队：成员、任务、材料、阶段  
- 待办中心四象限  
- 备赛日报图文与历史  
- 讲稿/材料；分端与校级隔离  

### 练
- 训练日任务与提交批改、可提前解锁  
- 本地视频进度、文档、外链  
- B 站内嵌 + 平台内学习时长（脚注：非精确拖动进度）  

### 演
- 多方在线路演、录制回放  
- 可上传视频评分  

### 评
- 多维 AI 评分与分栏报告  
- 师生同源报告  
- **脚注：辅助分析，非正式竞赛成绩**  

### 改
- 教师读报告、批改、审核发布任务  
- 学生待办跟进，再备/再练/再演  

**页底一句**：AI 助手 / 跟打 / PPT 辅助生成等为支线，服务「备」，非一键完赛。

## 第 5 页｜人（师生）

**任务**：角色互补。不列功能菜单。

### 学生
不是多做一遍，而是多会一点。  
备得实 · 练得准 · 演得出 · 看得懂评 · 改得明。  
平台给路径，不代替学会。

### 教师
把精力留给真正需要判断的地方。  
收齐过程 → 对照线索 → 裁决改什么 → 发布任务 → 下一轮验收。  
AI 出线索，教师出判断。

### 教务（一段）
节奏跑起来后，能看见过程：谁在备、练到哪、演过几轮、改有没有落地——而不只赛后看名次。

## 第 6 页｜可信

**任务**：全册边界只在这里完整出现一次。

**标题**：一次参赛，应留下可生长的方法。

| 平台能支撑看见的 | 仍需一起证明 |
|------------------|--------------|
| 备练演评改各环节过程信号 | 能力是否实质提升 |
| 教师判断写入改进路径 | 指导质量与效率 |
| 校级隔离与分端治理 | 赛场与长期育人成效 |

| 承诺的用法 | 不承诺 |
|------------|--------|
| 可复查的五字路径 | 金奖/名次 |
| AI 辅助，教师裁决 | AI 正式成绩/无人教师 |
| 过程留痕便于传承 | 勾选=已学会 |
| 材料可辅助生成、需打磨 | 一键完美 PPT |

**承诺句**：不替学生赢一场比赛，而是帮助学生长出赢得比赛的能力。
