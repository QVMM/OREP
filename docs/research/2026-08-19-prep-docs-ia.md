## 1. 为什么不能叫「资料库」，也不能并进资源中心

平台已经有 **资源中心**：放文件、版本、共享、上场材料包。它是文件柜。

本模块放的是 **可编辑的智能文档**：出处、判断、附图、附件。它是写作台。

若再叫「资料库」，老师会以为又是一个文件夹。若并进资源中心，智能文档会退化成附件列表。

**产品名：备赛文档。**

| | 资源中心 | 备赛文档 |
|---|---|---|
| 用户以为它是 | 文件柜 | 按赛题结构写的本子 |
| 存什么 | PPT、PDF、压缩包、版本 | 一篇篇智能文档 |
| 结构 | 文件夹 / 文件 | 主菜单 5 干 + 子菜单 22 叶 |
| 附件 | 文件本身 | 文档里的图/附件，走 MinIO 地址 |
| 和投影的关系 | 可被引用为原件 | 命题与证据从文档块抽出 |

侧栏放在「团队协作」下，与资源中心并列：任务管理 · 资源中心 · 备赛文档。

## 2. 主子菜单（必须有，但首页不是 22 个空夹）

后台仍是 22 叶本体。前台左侧永远是主子菜单。

```

├ 项目背景
│   ├ 时事新闻分析      ← MVP 第一条链
│   ├ 政策背景支撑
│   ├ 市场考察调研
│   └ 明确研发动因
├ 研发历程
│   ├ 产教融合
│   ├ 调研与痛点
│   ├ 问题策略
│   ├ 五层技术架构
│   ├ 安全与规范
│   └ 团队分工
├ 实施过程
│   ├ 产品经理
│   ├ 前端
│   ├ 后端
│   ├ 测试
│   └ 工匠精神
├ 创新设计
```

规则：

- 每个叶节点 = **一篇智能文档**（没有就显示「还没有这篇，点这里新建」）。

- 文档标题默认等于叶名，可改，但不改叶子身份。

## 3. 存储逻辑：内容只活在智能文档里

```
叶节点「时事新闻分析」
        │
        ▼
  inspire_office_document (ext=sdoc)
        │
        ▼
  inspire_smart_doc.content_json
        │
        ├─ 普通段落（人写）
        ├─ 出处块  → 抽出 rs_evidence
        ├─ 判断块  → 抽出 rs_claim
        ├─ 图片     → MinIO URL，禁止 base64
        └─ 附件卡片 → MinIO URL
```

`rs_evidence` / `rs_claim` 是从文档块抽出的投影用索引，不是老师要再填的第二套表单。老师只维护这一篇智能文档。

---

## 4. 附件与图片：必须走 MinIO，禁止粘贴进文档当正文

现状：智能文档已有 `uploadSmartDocAsset` → `/api/upload`，粘贴图片理论上会上传。实际老师侧是「复制进去不行、文件传不上去」。界面必须改成**显式上传**，不能只靠粘贴。

```
用户选图 / 选文件 / 拖进编辑器
        │
        ▼
  POST /api/upload  (category=images|files)
        │
        ▼
  MinIO 对象  →  返回 https URL
        │
        ▼
  文档 JSON 只存 URL + 文件名 + 大小
        │
        ✕ 禁止 data: 写入 sdoc
        ✕ 禁止把截图当文本粘进段落
```

粘贴图片：拦截 → 走同一上传 → 成功再插入。失败则提示「粘贴进正文不可用，请点上传」。

## 5. 和投影 MVP 的衔接（本 UI 先做文档，后做两页）

```
备赛文档 · 时事新闻分析（智能文档，8 个出处块）
        │ 人确认出处 / 判断
        ▼
  抽出 8 Evidence + 8 Claim
        │
        ▼
  Block 0 确定性选择器（已有测试）
        │
        ▼
  两页文字 + 讲稿 + 决策理由
```

本高保真先画：备赛文档壳、主子菜单、时事智能文档、MinIO 上传。两页投影是同一入口里的次屏，不另开产品门。

## 6. 逻辑图（实现对照）

### 6.1 分工

```
资源中心                    备赛文档
(文件柜)                    (写作台)
   │                           │
   │  原件 PPT/检测报告         │  智能文档
   │  可被出处块引用            │  块里挂 MinIO 图/附件
   └──────────► 出处 URL / file_id
```

### 6.2 写入

```
打开叶子 → 无文档则建 sdoc → 编辑
   → 插入出处块（链接或从资源中心选文件）
   → 上传图/附件（MinIO）
   → 写判断句
   → 点「出处没问题 / 可以上场候选」
   → 抽出 Evidence / Claim（老师看不见表名）
```

### 6.3 上传失败态（必须画进 UI）

| 情况 | 界面 |
|---|---|
| 上传中 | 文档内占位「正在传到文件库…」 |
| 成功 | 图或附件卡片，可点开 |
| 失败 | 「没传上去，请重试」；正文里不留碎图 |
| 粘贴截图 | 自动改走上传；失败则明确说粘贴不可用 |
| data: URL | 拒绝写入 |

## 7. 小启怎么融进去

小启用现有智能文档右侧栏，不另做聊天产品。

- 打开备赛文档时默认打开小启。
- 快捷说法只跟这篇有关：这篇还缺什么 / 核一下这条出处 / 写成一句能上台的话 / 这场先出哪两条。
- 选中一段再问，小启只改这一段。
- 改文档必须「确认写入」，和现在讲稿里一样。
- 「下一步」由小启说，不再单独做数据驾驶舱。
- 用户说「根据备赛文档生成一版 PPT」时，小启先做意图识别，再检查文档：能直接用 / 要压短 / 还缺。不够就明说，不编。
- 下一步不是出 PPT，而是另写一篇智能文档《这场路演的页稿》：开头写整场叙事，下面按页写内容与来源。人改这篇，确认后再做成演示。

界面禁止出现：MinIO、接口、库表、准备态、N4、硬成功。

## 8. 启发 Office 里怎么进（用户友好、路径要死）

备赛文档住在 **启发 Office** 里。学生来这里只有三件事：找一篇写、问小启、出这场页稿。三件事各有一个不会走丢的口。

```
AI 应用中心 → 启发 Office
                 │
                 ├ 顶上两张进法卡（目的明确的人从这里进）
                 │    ├ 问小启
                 │    │     → 先问「对着哪一篇」
                 │    │         ├ 最近一篇（默认）
                 │    │         ├ 这场页稿
                 │    │         └ 我自己在下面点一篇（夹只开合，点文件才打开 + 右侧小启）
                 │    └ 出这场页稿
                 │          → 直接打开《这场路演的页稿》
                 │            没有材料就是空骨架 + 四种来源
                 │
                 ├ 出品（始终钉住，不当普通叶子藏）
                 │    ├ 这场路演的页稿   始终在，不是小启写完才出现
                 │    └ 路演讲稿         有讲稿智能文档才钉；点进去是页稿的讲稿面
                 │
                 └ 五个文件夹（可折叠）
                      └ 叶子 = 一篇文件
                            ├ 有内容：文档图标 + 一句状态 + 核对标
                            └ 还没有：虚线文档图标 +「点这里新建」
```

三个人从同一页进来，不共用一个含糊按钮：

| 他来干什么 | 他点哪里 | 下一屏 |
|---|---|---|
| 就是来问小启 | 顶上「问小启」，或轨道栏小启 | 先选一篇，再打开这篇 + 右侧小启。不另开窗口，也不默认偷偷进时事。 |
| 就是来出页稿 / PPT | 顶上「出这场页稿」，或出品里那一行 | 《这场路演的页稿》。确认完再做成能翻的演示。 |
| 就是来写某一篇 | 打开对应文件夹，点那一行 | 有内容进编辑；没有就进空篇 +「新建这篇」。 |

规则：

1. **文件就长得像文件。** 叶子是文档行：折角页图标、标题、一句状态、核对标。空篇是虚线页，不是灰字清单。页稿、讲稿、备赛篇三种图标要能一眼分开。
2. **主菜单可折叠。** 五个干长得像文件夹。有内容的默认展开，空的收起。点干名只开合，不进编辑器。点叶子才打开那一篇。
3. **页稿始终钉在最上。** 目的就是出 PPT 的人，不用先翻 22 个夹，也不用先问小启。点进去就是 22 槽；没有材料就是空骨架。
4. **问小启有三个口，一个产品。** 轨道栏小启、Office 顶上「问小启」、打开任意文档后的右侧栏，都是同一个小启。小启必须挂在一篇文档右边，所以从 Office 进要先选篇。已经在某篇里点轨道栏，只拉开右侧栏，不换篇。
5. **全部文档** 是平铺文件表（页稿 + 讲稿 + 有内容的备赛篇）。备赛结构仍在「备赛文档」页。
6. **新建一篇** 不是空白无主文档。弹出还没有的叶子，人选一个再建。结构仍是 22 叶，不另开一套自由文档。
7. 资源中心仍只放 PPT / 附件原件。启发 Office 不替代资源中心。

## 9. 高保真范围

`prep-docs.html`：

1. 启发 Office 首页：进法卡 + 问小启先选篇 + 可折叠文件夹 + 文件行
2. 写时事 / 政策 / 调研，空叶子新建；「新建一篇」按夹列出空叶
3. 添加图片 / 附件
4. 小启确认才写入
5. 这场页稿始终可进；四种来源可切
