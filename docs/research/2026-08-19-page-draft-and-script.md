# 页稿与讲稿：四种来源怎么走

| 项 | 内容 |
|---|---|
| 日期 | 2026-08-19 |
| 产品 | 备赛文档 · 这场路演的页稿 |
| 高保真 | `OREP-高保真原型/user/prep-docs.html#pages`（顶上可切四种来源） |
| 配套 | 《新赛制路演PPT通用模板》22 槽；《新赛制路演讲稿模板-4人角色版》；页稿标准 `2026-08-19-page-draft-standard.md` |
| 不改 | 修订稿 E 对象模型。评分不拿来自动改稿。 |

本文管一件事：用户手里有或没有 PPT、有或没有讲稿时，**页稿上怎么显示、小启先干什么、什么进备赛文档**。生成 PPT 排在确认之后。

---

## 1. 四样东西不要混

| 东西 | 是什么 | 活在哪 |
|---|---|---|
| 备赛文档 | 事实：出处、判断、现场/政策/设备图 | 22 篇智能文档 |
| 页稿 | 还没排版的正式演示：页上文字、图、出处 | 一篇智能文档《这场路演的页稿》，骨架 22 槽 |
| 讲稿 | 这一页台上怎么说 | 智能文档里的讲稿；页稿上按槽挂出来 |
| PPT | 确认后的版式包装 | 资源中心 / 演示文件 |

依赖单向：**备赛文档 → 页稿（页上 + 讲稿）→ PPT**。  
禁止只改讲稿而页上还指着旧事实。禁止不确认就落盘。禁止整份自动重做逻辑。

讲稿不是另写一份长文。页稿上的「讲稿」就是那份智能文档按页切开的视图。

---

## 2. 上场骨架（所有来源都用这一套）

22 槽，P01–P22。递进：发现问题 → 寻求对策 → 规范实施 → 成果提炼 → 价值转化。

只允许在实施过程（P14–P17）按岗加厚。空槽标「本场不讲」，不编数、不加平行空页。

开场：先认人。问好、队名、项目名，一号到四号报岗位，再指图。后面换人像同事递话，不喊「我来接识别」。

每一槽七块：槽号/段/秒数 · 页上文字 · 页上图 · 出处 · 讲稿 · 本页不要 · 状态。

## 3. 四种来源

先看手里有没有讲稿、有没有 PPT。页稿骨架不变，变的是槽里填什么、小启先做什么。

```
                 有讲稿                         没有讲稿
           ┌─────────────────┐            ┌─────────────────┐
有 PPT     │  2  对稿          │            │  4  按页起草讲稿  │
           │  识别、对齐、标打架 │            │  页上从图来      │
           └─────────────────┘            └─────────────────┘
           ┌─────────────────┐            ┌─────────────────┐
没 PPT     │  1  讲稿挂上      │            │  3  空骨架        │
           │  页上短句待确认    │            │  先写备赛或起草   │
           └─────────────────┘            └─────────────────┘
```

高保真里用四个按钮切换，方便对照。真产品里由系统判断，不让学生选「我是哪种」。

### 3.1 有讲稿、没 PPT

**怎么显示**

- 22 槽都在。
- 讲稿：整篇按页切开，挂到槽上。切不开的整段进「待对页」，人点一下落到哪一槽。来源写：智能文档《××讲稿》。
- 页上文字：空，或给出「从讲稿压成的页上短句」，标 **待确认**。口述不能整段糊成页上字。
- 图：讲稿里点到的现场/政策/设备，备赛文档有就贴；没有就空。

**小启先干什么**

1. 说清：现在是有讲稿、还没有演示。  
2. 对页、压短句，等人确认。  
3. 不先出 PPT。

**进备赛文档**

讲稿里的事实、出处、提到的图，能入库的进对应那一篇。

### 3.2 有讲稿、也有 PPT（对稿）

材料最多，最容易乱动。页稿当对稿台，**不自动重做逻辑**。

**怎么显示**

- 页上文字、图：从 PPT 识别上来（修饰底不要）。
- 讲稿：按页或按口令对到同一槽，挂上。
- 对得上：并排。  
- 页上写 A、台上讲 B：标 **对不上**，左页上 / 右讲稿，等人点「以页为准 / 以讲为准 / 先不动」。

**小启先干什么**

1. 识别 PPT 结构，对到 22 槽。  
2. 识别讲稿，挂到槽。  
3. 能入库的图和出处拆进备赛文档。  
4. 只出诊断：哪槽对不上、哪句没出处、哪段该并。  
5. 人确认才改槽。禁止一上来整份重排。

**进备赛文档**

政策截图、现场照、设备、代码、出处 → 对应那一篇。这是入库，不是改演讲。

### 3.3 没讲稿、没 PPT

**怎么显示**

- 22 空槽，标题和任务还在。
- 页上文字、图、讲稿都写「还没有」。
- 讲稿区就一句：还没有讲稿。可以先写备赛文档，或让小启按骨架起草一版，确认后再用。

**小启先干什么**

默认先补备赛文档（时事、政策、调研），再起草页稿和讲稿草稿。不先出 PPT。

### 3.4 没讲稿、有 PPT

就是番茄这份的常见路。

**怎么显示**

- 页上文字、图：从 PPT 识别上来。
- 讲稿空着。按钮：**按这一页的字起草讲稿**。
- 起草用路演讲法：先认人、指图、短句；不编页上没有的数。

**小启先干什么**

按槽起草讲稿，确认后写入智能文档，并挂回这一槽。

**进备赛文档**

能认出来的图和出处入库，与 3.2 相同。

## 4. 页稿上「讲稿」那一块（四种长一样）

| 状态 | 区里写什么 |
|---|---|
| 有讲稿 | 台上要说的话。角标：来自《××讲稿》 |
| 有讲稿也对上 PPT | 同上；和页上打架就标「对不上」 |
| 都没有 | 还没有讲稿。先写备赛，或让小启按骨架起草。 |
| 只有 PPT | 还没有讲稿。按这一页的字起草。 |

不另开「讲稿模块」和第二套页序。

---

## 5. 小启开口顺序

无论哪种来源，先说现在属于哪一种，再动。

1. 判断：有没有讲稿、有没有 PPT。  
2. 说给人听（不要内部词）。  
3. 只做这一步该做的：对页 / 压短句 / 起草 / 标打架。  
4. 等人点确认。不确认不落盘。  
5. 页稿齐了，才说「可以按这些页做成能翻的演示」。

---

## 6. 和评分、智能文档的关系

- 评分只作对照，不拿来自动改页、改讲稿。  
- 智能文档里的讲稿 = 页稿讲稿区的源。改一处，另一处跟着，不要两份各改各的。  
- 资源中心继续放 PPT 文件。页稿不替代资源中心。

---

## 7. 从启发 Office 怎么进

备赛文档住在启发 Office。顶上两张卡，两件不同的事：

- **问小启**：先问对着哪一篇（最近一篇 / 这场页稿 / 自己点一篇），再打开这篇 + 右侧小启。轨道栏小启是同一个，不另开窗口。
- **出这场页稿**：直接打开《这场路演的页稿》。没有材料就是空骨架。

页稿始终钉在文件夹上面，不用等小启写完才出现。五个主菜单是可折叠的文件夹，叶子是文件行：有内容是实页图标，没有是虚线页 +「点这里新建」。

详见 `2026-08-19-prep-docs-ia.md` 第 8 节。

## 8. 高保真怎么看

打开 `OREP-高保真原型/user/prep-docs.html`，进「这场路演的页稿」。顶上四个来源：

1. 有讲稿 · 没 PPT  
2. 讲稿和 PPT 都有  
3. 都没有  
4. 有 PPT · 没讲稿  

默认「都有」，方便看对不上。切到「都没有」看空骨架。切到「有 PPT · 没讲稿」看起草按钮。

小启侧栏会跟着说来源，并给出这一步该点的按钮。
