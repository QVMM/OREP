# 页稿标准（新赛制路演）

| 项 | 内容 |
|---|---|
| 日期 | 2026-08-19 |
| 依据 | 《新赛制路演PPT通用模板.pptx》（刘一星，22 页上场骨架 + 4 页说明书） |
| 四种来源 | 见 `2026-08-19-page-draft-and-script.md`（有/无讲稿 × 有/无 PPT） |
| 管什么 | 小启怎么写页稿、人怎么确认、后面 PPT 按什么页序装 |
| 不管什么 | 版式、配色、动画。那些是生成 PPT 时的事 |

页稿是还没排版的正式演示。标准先定页序和每页任务，再往里填字和图。

---

## 1. 三层不要混

| 层 | 是什么 | 不是什么 |
|---|---|---|
| 备赛文档 | 22 篇材料怎么写 | 不是上场页序 |
| 页稿 | 按骨架写成的正式演示内容 | 不是 22 叶各摊一页，也不是 40 页空壳 |
| PPT | 把已确认页稿装进版式 | 不是这一步再发明结构 |

说明书那 4 页（逻辑、全景、评分映射、漏分点）给做 PPT 的人看，**不上场，不进页稿正文**。

---

## 2. 上场骨架固定 22 槽

递进只有一条：

**发现问题 → 寻求对策 → 规范实施 → 成果提炼 → 价值转化**

五段、22 槽、右下角页码，与通用模板一致：

| 槽 | 段 | 页上要完成的事 | 主要吃哪篇备赛文档 | 钉在哪项分 |
|---|---|---|---|---|
| P01 | 封面 | 名字、代号、自己项目的图 | 调研 / 产品图 | — |
| P02 | 目录 | 五段，可按项目改短 | — | — |
| P03 | 背景 | 一条已核对时事，把问题说急 | 时事新闻分析 | 应用价值 |
| P04 | 背景 | 文件原件 + 这条要我们做什么 | 政策背景支撑 | 应用价值 |
| P05 | 背景 | 市场/对照数据，接到本项目 | 时事或市场考察 | 应用价值 |
| P06 | 历程 | 企业/学校在本项目里具体做什么 | 产教融合 | 职业素养 |
| P07 | 历程 | 现场图 + 调研数据 → 痛点 | 调研与痛点 | 职业素养 |
| P08 | 历程 | **问题与对策 1:1**，有几条写几条 | 问题策略 | 技能水平 |
| P09 | 历程 | 五层用本项目对象命名 | 五层技术架构 | 技能水平 |
| P10 | 历程 | 落到哪条规范，检查过没有 | 安全与规范 | 职业素养 |

| P12 | 历程 | 四人职责，不要花名册 | 团队分工 | 团队合作 |
| P13 | 历程 | 一次全周期安排或一次返工 | 工匠精神 | 职业素养 / 技能 |
| P14 | 实施 | 产品经理：对回 P08，流程+对比 | 产品经理 | 技能水平 |

| P17 | 实施 | 测试：测过/没过，不要全绿空话 | 测试 | 技能水平 |

骨架号 P01–P22 不改。项目不同，改的是槽里的字和图，不是另起一套页序。

## 3. 什么时候可以加页，什么时候必须删页

**只允许在实施过程加页。** P14–P17 每一岗材料够，就按「职责 → 对回 P08 → 流程 → 结果/对比」往下加，一岗最多约 5 页。加页编号：`P14-1`、`P14-2`，不要另起第 23 个骨架。

其他槽不加平行空页。尤其禁止：

- 痛点 1 / 2 / 3 各一页、策略 1 / 2 / 3 各一页（对策只留在 P08，1:1 写成行）
- 五层拆成采集、识别、分槽、复核四页（只留 P09，细节进 P11 或实施）
- 为凑 38 页而复制岗位说明书
- 把说明书、评分表、备用问答编进上场序号

**材料不够的槽：本场不讲。** 页稿里仍保留这一槽，标「本场不讲」，不算上场页，不编假字假数。宁缺，不占位。

本场上场页数 = 22 个槽里「可上屏」的 + 实施过程加出来的。1 小时场常见落在 30–40；那是加厚实施的结果，不是起写时的目标。

## 4. 每一页必须写的七块

1. **槽号 / 段 / 约几秒**  
2. **页上文字**（按正式演示一页写满：导语、分点、对照表。不是三四条提纲。没有的事实标【待补】，不编数）  
3. **页上图**（只放备赛文档里已有的政策、现场、设备、产品、任务、代码、曲线。背景和修饰不上页稿）  
4. **出处**（哪一篇、哪一条、核过没有）  
5. **讲稿**（这一页上台怎么说。按路演讲法写满，对着页能讲，不是一句话备注）

路演讲法：四人队开场一起站，每人一句自己是谁、管哪一段，再指图；像跟评委老师说话，不念注意事项；自己的痛点自己接。篇幅跟秒数走。  
6. **本页不要**  
7. **状态**：可上屏 / 待补 / 本场不讲  

图的规矩：同一张现场照可以在封面、背景、痛点、收束复用。能拿来用就直接贴，不要写成「此处放田间图」。

## 5. 从备赛文档到页稿

小启写页稿的顺序：

1. 先对 22 槽做完备性：哪槽已有可上台材料，哪槽没有。  
2. 能直接用的贴上（含图）。要压短的压成页上短句。没有的标「本场不讲」。  
3. 检查 P08：问题和对策是否 1:1；对不上的对策不上页。  
4. 检查 P14–P17：是否对回 P08；有材料才加厚。  
5. 检查 P18–P21：有没有引入前面没讲过的新事实。  
6. 人改页稿。不确认，不生成 PPT。

生成 PPT 只做三件事：按上场序号翻页、套版式、把页稿上的图和字装进去。不再改结构。

## 6. 和评分的关系（只作对照，不用来改稿）

| 评分大项 | 主要看哪些槽 |
|---|---|
| 技能水平 60% | P08、P09、P11、P13、P14–P17 |
| 职业素养 10% | P06、P07、P10、P13 |
| 应用价值 10% | P03–P05、P20–P21 |
| 团队合作 10% | P12，以及 P14–P17 里的联调一句 |
| 创新创意 10% | P18–P19，必须针对 P07/P08 |

漏分补强（联合排障、证书/就业、可持续）有材料再写入对应槽，没有就本场不讲。禁止为抬分整份重写。

---

## 7. 实例怎么用这份标准

番茄项目是第一份实例：页稿按 P01–P22 列槽，已有现场/政策/设备/代码图直接贴；产教、规范、多数岗位实操标「本场不讲」或「待补」；实施过程不先铺 20 页空壳。
