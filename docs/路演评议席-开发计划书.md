**Goal:** 在现有 Session + 规则账本上补齐四件硬规格：冻结卷宗复评、实质核验、任务书、满分差距，先把稳定性从「合成绿、实况无法检验」抬到「同卷宗三次分差可落库、可展示、可红标」。

**Tech Stack:** Java 17 + Spring + MyBatis-Plus + MySQL / H2 单测；Python FastAPI `ai-scoring` 流水线；Vue 3 学生/教师报告页。

## 3. 难点、解法、稳定性怎么加

### 3.1 总难点（按杀伤力）

| # | 难点 | 为什么难 | 解法 | 不做什么 |
|---|------|----------|------|----------|
| D1 | **三次分存不下来** | 产品把「一场」做成「一行 session + 一行 report」 | 场=`docket`，次=`run`；report 仍是「当前权威稿」 | 不删 uk_session（防一场多官方分） |
| D2 | **身份缺视频哈希** | fingerprint 按会议/项目，不按文件 | `docketId=sha256(videoSha256\|ruleVersion\|ruleHash\|contractVersion\|trackId)` | 不把 meetingId/projectId 放进 docket |
| D3 | **视频哈希在建 session 之后才有** | `createSession` 时文件还没上传 | 上传/登记素材成功后再 `bindDocket`；未绑定禁止 completed | 不在无哈希时编造 docket |
| D4 | **合成绿会骗人** | pilot 报告 sourceMode 是合成 | 新门禁分「账本层 / 卷宗层 / 实况层」；实况未测就写无法检验 | 不用旧 ready 当 G1 |
| D5 | **LLM 叙述漂** | 报告文案 temp>0 | 官方分只走账本；复评禁止温度采样重写分 | 不为了好看重抽分 |
| D6 | **教师确认是假门** | UI 有、状态机无 | `await_teacher` 默认挡住学生终局与待办 | 不把确认当装饰 |
| D7 | **覆盖面诱惑** | 9 人席、雷达、联网审查都像爆点 | 席位后做；检索默认关 | 不上皮肤冒充硬规格 |

## 4. 每个技术节点的 5–7 种预判问题与规避

### N1 `docketId` 计算

| # | 可能出什么 | 概率感 | 预先怎么防 | 验收信号 |
|---|------------|--------|------------|----------|
| 1 | createSession 时还没有 file_hash | 高 | 分两阶段：create 不写 docket；bind 在素材落哈希后 | 无哈希 session 的 docket_id 为空 |
| 2 | 会议回放没走上传，hash 空 | 中 | `registerMeetingRecordingAsset` 必须算 sha256，失败则 status≠ready | 空哈希不能 completed |
| 3 | 大小写 / 空格导致同文件不同 docket | 中 | sha256 统一小写 hex；字段 trim | 单测大小写 |
| 4 | 把 meetingId 塞进 docket，同文件不同会变两场 | 中 | 五元组写死，禁止加业务外键 | 代码审查 + 单测 |
| 5 | contractVersion 空串 vs null 分裂卷宗 | 中 | bind 时强制非空，默认 `ai-score-report-v3` | 单测 |
| 6 | 规则文件改了但 hash 没重算 | 低 | 沿用现有 `rubric_hash`；换 hash 必须新 docket | 换 hash 单测 |
| 7 | 预处理转码后 hash 变了被当成新场 | 中 | docket 锁定 **原始上传** hash，不锁转码后文件 | 文档 + bind 用源 asset |

### N2 run 历史表与唯一约束

| # | 可能出什么 | 概率感 | 预先怎么防 | 验收信号 |
|---|------------|--------|------------|----------|

## 6. 步骤 1 冻结契约（后面步骤不许改名）

```text
docketId = lowercase-hex-sha256(
  "videoSha256=" + lower(trim(videoSha256)) +
  "|ruleVersion=" + trim(ruleVersion) +
  "|ruleHash=" + lower(trim(ruleHash)) +
  "|contractVersion=" + trim(contractVersion) +
  "|trackId=" + trim(trackId)
)
```

缺任一非空字段 → 抛 `IllegalArgumentException`，**不准**用空串凑哈希。

默认 `contractVersion`：`ai-score-report-v3`（现网报告合同）。  
改阈值或核验合同：bump 到 `ai-score-report-v4` 等，自动新开 docket。

### 6.1 表 `ai_score_docket`

| 列 | 类型 | 约束 |
|----|------|------|
| docket_id | VARCHAR(64) | PK |
| video_sha256 | VARCHAR(64) | NOT NULL |
| rule_version | VARCHAR(64) | NOT NULL |
| rule_hash | VARCHAR(128) | NOT NULL |
| contract_version | VARCHAR(64) | NOT NULL |
| track_id | VARCHAR(64) | NOT NULL |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP |
| UNIQUE | (video_sha256, rule_version, rule_hash, contract_version, track_id) | `uk_docket_identity` |

### 6.2 表 `ai_score_docket_run`

| 列 | 类型 | 约束 |
|----|------|------|
| id | BIGINT | PK AI |
| docket_id | VARCHAR(64) | NOT NULL，索引 |
| run_index | INT | NOT NULL |
| session_id | BIGINT | NOT NULL |

| official_score | DECIMAL(5,2) | NULL 直到成功 |

| transcript_coverage | DECIMAL(6,4) | 0–1 |

| UNIQUE | (docket_id, run_index) | `uk_docket_run` |

        contract.setContractVersion("ai-score-report-v4");
        DocketIdentity track = base();
        track.setTrackId("track-other");
        assertNotEquals(service.docketId(base()), service.docketId(contract));
        assertNotEquals(service.docketId(base()), service.docketId(track));
    }

    @Test
    void normalizesCaseAndTrim() {
        DocketIdentity dirty = base();
        dirty.setVideoSha256("  " + "AA".repeat(32) + "  ");
        dirty.setRuleHash("  " + "DD".repeat(32).toUpperCase() + "  ");
        DocketIdentity clean = base();
        clean.setVideoSha256("aa".repeat(32));
        clean.setRuleHash("dd".repeat(32));
        assertEquals(service.docketId(clean), service.docketId(dirty));
    }

    @Test
    void rejectsMissingFields() {
        DocketIdentity missingVideo = base();
        missingVideo.setVideoSha256("  ");
        assertThrows(IllegalArgumentException.class, () -> service.docketId(missingVideo));
        assertThrows(IllegalArgumentException.class, () -> service.docketId(null));
    }

    private DocketIdentity base() {
        DocketIdentity identity = new DocketIdentity();
        identity.setVideoSha256("aa".repeat(32));
        identity.setRuleVersion("v1.2");
        identity.setRuleHash("dd".repeat(32));
        identity.setContractVersion("ai-score-report-v3");
        identity.setTrackId("track-c889f0110e2d");
        return identity;
    }
}
